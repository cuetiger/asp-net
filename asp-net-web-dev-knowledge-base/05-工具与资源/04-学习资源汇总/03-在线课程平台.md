# 在线课程平台：ASP.NET 学习资源全景导航

## 概述

在数字化学习时代，在线课程已成为获取技术知识的重要途径。相比传统书籍，视频课程具有直观、互动性强、更新及时等优势。本文档系统梳理了全球主流在线教育平台上的ASP.NET/.NET相关课程，涵盖免费和付费资源、中文和英文内容、入门到高级的完整学习路径。

**文档价值**：
- 节省你筛选课程的时间（已从数百门课程中精选50+门优质课程）
- 提供不同平台的对比分析，帮你做出最佳选择
- 按照学习路径组织，避免"不知道该学什么"的困惑
- 包含真实的学习体验评价和避坑指南

### 2.3 B站学习技巧

**高效使用B站学技术的建议**：

1. **善用播放列表(Playlist)**
   - 大多数UP主会将系列课整理成合集
   - 点击"合集"按钮可以按顺序观看
   - 收藏整个播放列表方便后续学习

2. **倍速播放**
   - 已懂的内容用1.5x或2.0x速
   - 新概念用正常速度或0.75x
   - 节省时间提高效率

3. **利用弹幕和评论**
   - 弹幕里常有补充说明和纠错
   - 评论区的置顶帖通常有配套资料链接
   - 遇到问题可以在评论区提问

4. **配合笔记软件**
   - 使用Obsidian/Notion记录关键点
   - 截图保存重要代码片段
   - 标记时间戳方便回看

5. **注意版本时效性**
   - 检查视频发布时间和使用的.NET版本
   - 新版本可能有API变化
   - 结合官方文档确认当前最佳实践

### 7.2 如何高效利用YouTube学习

**YouTube学习工作流**：

1. **建立学习播放列表**
   - 创建私有Playlist分类收藏视频
   - 按主题组织（如"ASP.NET Core基础"、"C#高级"、"架构设计"）
   - 标记已看完的视频（用"已学"前缀）

2. **主动学习而非被动观看**
   - 准备好IDE，边看边敲代码
   - 暂停视频预测下一步
   - 尝试修改代码观察结果
   - 记录疑问点后续查阅文档

3. **利用YouTube功能**
   - 开启字幕（自动翻译成中文）
   - 调整播放速度（0.75x-2.0x）
   - 使用时间戳跳转（点击描述中的时间）
   - 点赞和保存好视频

4. **注意视频时效性**
   - 检查发布日期和使用的.NET版本
   - 优先看近6个月的新视频
   - 对于经典教程注意版本差异提示

## 八、学习计划制定指南

### 8.1 不同目标的课程搭配方案

#### 方案A：零基础转行（6个月计划）

**目标**：从零基础到能独立开发中小型Web应用

**阶段一：第1-2个月（打基础）**
- **Microsoft Learn**："Build web apps with ASP.NET Core" 路径（25小时）

- **实践**：克隆eShopOnWeb项目并理解其架构
