# Todo应用 - 步骤1：项目初始化

## 一、概述

本步骤将从头开始搭建Todo应用的完整项目骨架，包括：

- ✅ 创建解决方案（Solution）和多层项目结构
- ✅ 配置ASP.NET Core MVC框架
- ✅ 集成Entity Framework Core
- ✅ 配置数据库连接
- ✅ 设置依赖注入容器
- ✅ 验证项目能够成功运行

**预计耗时：** 30-45分钟

**前置要求：**
- 已安装 .NET 8.0 SDK
- 已安装 Visual Studio 2022 或 VS Code
- 已安装 SQL Server LocalDB（随VS自动安装）

## 二、项目架构设计

### 2.1 分层架构说明

本项目采用**三层架构 + 依赖注入**模式：

```
┌─────────────────────────────────────────────┐
│              表现层 (Presentation)            │
│         TodoApp.Api (MVC Project)            │
│  - Controllers (控制器)                      │
│  - Views (Razor视图)                         │
│  - ViewModels (视图模型)                     │
│  - wwwroot (静态资源)                        │
├─────────────────────────────────────────────┤
│              业务逻辑层 (Business)            │
│          TodoApp.Core (Class Library)        │
│  - Entities (实体类)                         │
│  - Interfaces (接口定义)                     │
│  - Enums (枚举)                              │
│  - DTOs (数据传输对象)                       │
├─────────────────────────────────────────────┤
│            数据访问层 (Data Access)           │
│    TodoApp.Infrastructure (Class Library)     │
│  - Data/DbContext                            │
│  - Repositories (仓储实现)                    │
│  - Migrations (数据库迁移)                    │
└─────────────────────────────────────────────┘
```

### 2.2 项目职责划分

| 项目 | 类型 | 职责 | 引用关系 |
|------|------|------|---------|
| **TodoApp.Api** | ASP.NET Core Web App | 处理HTTP请求、返回HTML响应 | → Core, Infrastructure |
| **TodoApp.Core** | Class Library | 定义实体、接口、业务规则 | 无依赖（最底层） |
| **TodoApp.Infrastructure** | Class Library | 实现数据访问、EF Core配置 | → Core |
| **TodoApp.Tests** | xUnit Test Project | 单元测试和集成测试 | → Core, Infrastructure |

## 三、创建项目和解决方案

### 3.1 使用命令行创建（推荐）

打开 PowerShell 或命令提示符，执行以下操作：

#### 步骤1：创建根目录和解决方案

```bash
# 创建项目根目录
mkdir TodoApp
cd TodoApp

# 创建解决方案文件
dotnet new sln -n TodoApp
```

**输出结果：**
```
已创建模板"solution file"。
已成功创建 "C:\Projects\TodoApp\TodoApp.sln"
```

#### 步骤2：创建各层项目

```bash
# 创建src和tests目录
mkdir src
mkdir tests

# 创建API项目（MVC）
cd src
dotnet new mvc -n TodoApp.Api -o TodoApp.Api --no-https

# 创建Core类库
dot new classlib -n TodoApp.Core -o TodoApp.Core

# 创建Infrastructure类库
dot new classlib -n TodoApp.Infrastructure -o TodoApp.Infrastructure

# 回到根目录
cd ..

# 创建测试项目
cd tests
dot new xunit -n TodoApp.Tests -o TodoApp.Tests
cd ..
```

**参数说明：**
- `--no-_https`：开发环境禁用HTTPS（简化配置）
- `-o`：指定输出目录

#### 步骤3：将项目添加到解决方案

```bash
# 添加所有项目到解决方案
dotnet sln add src/TodoApp.Api/TodoApp.Api.csproj
dotnet sln add src/TodoApp.Core/TodoApp.Core.csproj
dotnet sln add src/TodoApp.Infrastructure/TodoApp.Infrastructure.csproj
dotnet sln add tests/TodoApp.Tests/TodoApp.Tests.csproj
```

**验证：**
```bash
# 查看解决方案中的项目列表
dotnet sln list
```

**预期输出：**
```

==========
src/TodoApp.Api/TodoApp.Api.csproj
src/TodoApp.Core/TodoApp.Core.csproj
src/TodoApp.Infrastructure/TodoApp.Infrastructure.csproj
tests/TodoApp.Tests/TodoApp.Tests.csproj
```

## 六、核心代码实现

### 6.1 Program.cs - 应用程序入口

**文件位置：** `src/TodoApp.Api/Program.cs`

这是ASP.NET Core应用程序的核心配置文件，负责：

- 配置依赖注入（DI）容器
- 注册服务和中间件
- 配置数据库连接
- 启动Web服务器

```csharp
using Microsoft.EntityFrameworkCore;
using TodoApp.Infrastructure.Data;

// ============================================
// TodoApp - ASP.NET Core MVC 应用程序入口
// ============================================

var builder = WebApplication.CreateBuilder(args);

// ============================================
// 1️⃣ 配置服务 (Services Configuration)
// ============================================

// --- MVC服务 ---
// 添加Controllers和Views支持
builder.Services.AddControllersWithViews(options =>
{
    // 全局过滤器配置（可选）
    // options.Filters.Add<AutoValidateAntiforgeryTokenAttribute>();
});

// 开发环境下启用运行时编译（修改View后无需重启）
if (builder.Environment.IsDevelopment())
{
    builder.Services.AddRazorRuntimeCompilation();
}

// --- 数据库服务 ---
// 配置Entity Framework Core和SQL Server连接
var connectionString = builder.Configuration.GetConnectionString("DefaultConnection")
    ?? throw new InvalidOperationException("Connection string 'DefaultConnection' not found.");

builder.Services.AddDbContext<ApplicationDbContext>(options =>
{
    options.UseSqlServer(connectionString, sqlOptions =>
    {
        // SQL Server特定配置
        sqlOptions.EnableRetryOnFailure(
            maxRetryCount: 3,                // 最大重试次数
            maxRetryDelay: TimeSpan.FromSeconds(30),  // 最大重试延迟
            errorNumbersToAdd: null);        // 要重试的错误码

        // 开发环境打印SQL语句（调试用）
        if (builder.Environment.IsDevelopment())
        {
            options.LogTo(Console.WriteLine, LogLevel.Information);
            options.EnableSensitiveDataLogging();  // 显示敏感数据（仅开发环境）
        }
    });
});

// --- Repository注册 ---
// 将在步骤2中实现
// builder.Services.AddScoped<ITodoRepository, TodoRepository>();

// --- Service注册 ---
// 将在步骤2中实现
// builder.Services.AddScoped<ITodoService, TodoService>();

// ============================================
// 2️⃣ 构建应用 (Build Application)
// ============================================
var app = builder.Build();

// ============================================
// 3️⃣ 配置HTTP请求管道 (Middleware Pipeline)
// ============================================

// 开发环境异常页面
if (app.Environment.IsDevelopment())
{
    app.UseDeveloperExceptionPage();
}
else
{
    // 生产环境配置
    app.UseExceptionHandler("/Home/Error");
    // HTTP严格传输安全（HSTS）
    app.UseHsts();
}

// 强制HTTPS（如需要）
// app.UseHttpsRedirection();

// 静态文件服务（wwwroot目录）
app.UseStaticFiles();

// 路由配置
app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Home}/{action=Index}/{id?}");

// ============================================
// 4️⃣ 数据库初始化 (Database Seeding)
// ============================================

// 应用启动时初始化种子数据（仅在开发环境）
using (var scope = app.Services.CreateScope())
{
    var services = scope.ServiceProvider;
    var logger = services.GetRequiredService<ILogger<Program>>();

    try
    {
        var context = services.GetRequiredService<ApplicationDbContext>();

        // 确保数据库存在并应用最新迁移
        // 注意：首次运行时会自动创建数据库
        await context.Database.MigrateAsync();

        // 初始化种子数据
        await SeedData.InitializeAsync(context);

        logger.LogInformation("数据库初始化完成");
    }
    catch (Exception ex)
    {
        logger.LogError(ex, "数据库初始化时发生错误");
        throw;  // 初始化失败则终止应用启动
    }
}

// ============================================
// 5️⃣ 启动应用 (Run Application)
// ============================================
app.Run();
```

**代码详解：**

#### 关键点1：AddDbContext 配置

```csharp
builder.Services.AddDbContext<ApplicationDbContext>(options =>
{
    options.UseSqlServer(connectionString);
});
```

- 注册`ApplicationDbContext`到DI容器
- 默认生命周期为**Scoped**（每个请求一个实例）
- 从`appsettings.json`读取连接字符串

#### 关键点2：UseSqlServer 配置选项

```csharp
sqlOptions.EnableRetryOnFailure(...)
```

- **弹性策略**：网络抖动时自动重试
- **开发日志**：打印生成的SQL，方便调试
- **敏感数据**：开发环境显示参数值

#### 关键点3：数据库迁移

```csharp
await context.Database.MigrateAsync();
```

- 自动应用待执行的迁移
- 如果数据库不存在会自动创建
- 保证数据库结构与代码同步

#### 关键点4：错误处理

```csharp
catch (Exception ex)
{
    logger.LogError(ex, "数据库初始化失败");
    throw;  // 终止启动，避免带病运行
}
```

**配置说明：**

## 八、创建初始迁移

### 8.1 执行迁移命令

在包含解决方案文件的目录下执行：

```bash
# 进入Api项目目录（作为启动项目）
cd src/TodoApp.Api

# 添加初始迁移
dotnet ef migrations add InitialCreate \
    --project ../TodoApp.Infrastructure \
    --startup-project . \
    --context ApplicationDbContext \
    --output-dir Data/Migrations
```

**参数说明：**

| 参数 | 值 | 说明 |
|------|-----|------|
| `--project` | `../TodoApp.Infrastructure` | DbContext所在的项目 |
| `--startup-project` | `.` | 当前目录（Api项目），用于读取配置 |
| `--context` | `ApplicationDbContext` | 指定DbContext类型 |
| `--output-dir` | `Data/Migrations` | 迁移文件的输出目录 |

**成功输出示例：**
```
正在执行操作...
正在编写 '...\Data\Migrations\20260416000000_InitialCreate.cs'
正在写入快照...
Done. 若要撤销此操作，请使用 'ef migrations remove'
```

### 8.2 应用迁移创建数据库

## 十、常见问题及解决方案

### 问题1：dotnet ef 命令找不到

**错误信息：**
```
'dotnet ef' 无法识别为内部或外部命令
```

**原因：** 未安装EF Core CLI工具或未在当前项目引用

**解决方案：**

```bash
# 方法1：本地安装（推荐）
dotnet add package Microsoft.EntityFrameworkCore.Tools
dotnet restore

# 方法2：全局安装
dotnet tool install --global dotnet-ef
```

**验证安装：**
```bash
dotnet ef --version
# 应输出版本号，如 8.0.x
```

---

### 问题2：LocalDB连接失败

**错误信息：**
```
A network-related or instance-specific error occurred while establishing a connection to SQL Server.
```

**排查步骤：**

1. **确认LocalDB已安装**
   ```bash
   sqllocaldb info
   ```

2. **启动LocalDB实例**
   ```bash
   sqllocaldb start mssqllocaldb
   ```

3. **检查连接字符串**
   - 确认实例名是 `mssqllocaldb`（不是 `MSSQLLocalDB`）
   - 确认反斜杠转义：`\\mssqllocaldb`

4. **使用Visual Studio验证**
   - 视图 → SQL Server 对象资源管理器
   - 尝试手动连接

---

### 问题3：迁移冲突

**场景：** 多人协作时，迁移文件冲突

**解决方案：**

```bash
# 合并前先更新远程迁移
git pull origin main

# 如果有冲突，解决后重新生成迁移
dotnet ef migrations remove  # 删除本地迁移
dotnet ef migrations add NewMigrationName
```

---

### 问题4：端口被占用

**错误信息：**
```
Unable to bind to http://localhost:5000 on IPv4 loopback interface.
```

**解决方案：**

**方法1：使用其他端口**
```bash
dotnet run --urls "http://localhost:5001"
```

**方法2：查找并结束占用进程**

```bash
# Windows PowerShell
netstat -ano | findstr :5000
```

```json
      }
    }
  }
}
```

---

### 问题5：种子数据重复插入

**现象：** 每次重启应用，数据都会翻倍

**原因：** SeedData中没有检查是否已有数据

**解决方案：** SeedData代码中已包含此检查：

```csharp
if (await context.TodoItems.AnyAsync())
{
    return;  // 已有数据，跳过插入
}
```

确保这段代码存在且正确。

---

### 问题6：编译警告 CS8618

**警告信息：**
```
Warning CS8618: Non-nullable property 'Title' must contain a non-null value when exiting constructor.
```

**原因：** 启用了可空引用类型，但属性未在构造函数中初始化

**解决方案：**

**方法1：使用默认值（推荐）**
```csharp
public string Title { get; set; } = string.Empty;
```

**方法2：使用null包容运算符**
```csharp
public DbSet<TodoItem> TodoItems { get; set; } = null!;
```

**方法3：禁用可空引用（不推荐）**
```xml
<PropertyGroup>
  <Nullable>disable</Nullable>
</PropertyGroup>
```
