## ⚠️ 重点提醒

### 🔥 必须掌握的核心概念（不然后面会很痛苦）

1. **MVC 的职责分离** - 如果不理解这个，后面所有内容都会混乱
2. **EF Core 的 DbContext** - 数据库操作的入口，必须熟悉
3. **DI 的生命周期** - Transient/Scoped/Singleton，用错会有大坑
4. **中间件执行顺序** - 先注册的先执行（对响应来说是反的）

### 💡 学习建议

1. **边学边做**：每学一个概念就立刻在代码中实践
2. **画图理解**：用纸笔画出 MVC 的请求流程、EF Core 的查询过程
3. **对比学习**：对比 Code First vs Database First、不同生命周期的区别
4. **造轮子**：尝试自己实现简化版的 DI 容器或 ORM（加深理解）
5. **阅读源码**：看 ASP.NET Core 的开源代码，学习设计思路

### 🚨 常见误区

❌ **只看不练** → 必须亲手写每一行代码  
❌ **跳过 EF Core 直接用 SQL** → EF Core 是企业开发标准  
❌ **不理解 DI 就乱用** → 会导致各种奇怪的问题  
❌ **忽略中间件顺序** → 可能导致安全漏洞或功能异常  
❌ **Todo 项目敷衍了事** → 这是综合能力的检验
