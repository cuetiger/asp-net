## 💡 核心内容

### 一、什么是.NET SDK？

**SDK** = **S**oftware **D**evelopment **K**it（软件开发工具包）

简单来说，.NET SDK就是一个"工具箱"，里面包含了：
- **.NET 运行时** - 让你的程序能够运行的环境
- **编译器** - 将你写的代码翻译成计算机能理解的指令
- **开发工具** - 创建项目、管理依赖包、运行测试等命令行工具
- **类库** - 预先写好的代码模块，可以直接使用（比如处理字符串、操作文件等）

> **🎯 类比理解：** 如果你要做菜，.NET SDK就像是一个完整的厨房套装——包括炉灶（运行时）、刀具（编译器）、调料（类库）和各种厨具（开发工具）。没有这个工具箱，你就无法开始烹饪（编程）。

### 二、选择哪个版本？

#### 版本类型说明

| 版本类型 | 说明 | 推荐人群 |
|----------|------|----------|
| **LTS (长期支持版)** | 微软官方维护3年，稳定可靠，适合生产环境 | ✅ **新手首选** |
| **STS (标准支持期)** | 维护18个月，功能较新但稳定性稍差 | 有经验的开发者 |
| **Preview (预览版)** | 测试版本，可能有bug，功能最新 | 想尝鲜的开发者 |

#### 当前推荐版本（2024年）

> [!tip] 📸 操作提示
> 访问 https://dotnet.microsoft.com/download ，选择 **.NET 8.0 LTS** 版本

**强烈建议新手选择 LTS 版本！** 目前推荐的LTS版本：
- **.NET 8.0 LTS** (推荐) - 最新的长期支持版本，支持到2026年11月
- **.NET 6.0 LTS** (备选) - 较老的LTS版本，如果需要兼容旧项目可选

### 三、下载 .NET SDK

#### 步骤1：打开官方下载网站

访问微软官方下载页面：
🔗 **https://dotnet.microsoft.com/download**

> [!tip] 📸 操作提示
> 点击 **"下载 .NET SDK"** 按钮（非 Runtime）

#### 步骤2：选择下载版本

1. 在页面上找到 **".NET SDK"** 区域
2. 点击 **"Download .NET SDK"** 按钮
3. 选择 **".NET 8.0 SDK"** （或最新的LTS版本）
4. 确保下载的是 **x64** 版本（适用于64位Windows）

> [!tip] 📸 操作提示
> 选择 **x64** 架构，点击蓝色 **"下载"** 按钮

#### 下载文件说明

下载完成后你会得到一个安装程序文件，文件名类似于：
- `dotnet-sdk-8.0.401-win-x64.exe` (约200MB)

> **⚠️ 注意：** 文件名中的数字可能因版本更新而不同，这是正常的。只要看到 `dotnet-sdk` 开头且包含 `win-x64` 就是对的文件。

### 四、安装 .NET SDK

#### 安装步骤详解

**步骤1：运行安装程序**

1. 找到下载好的 `.exe` 文件
2. **双击运行**（可能需要管理员权限）
3. 如果弹出用户账户控制提示，点击 **"是"**

> [!tip] 📸 操作提示
> 双击下载的 `.exe` 文件，出现安装向导

**步骤2：同意许可协议**

1. 阅读许可条款（虽然很少有人真的读完😄）
2. 勾选 **"我同意许可条款和隐私声明"**
3. 点击 **"安装"** 按钮

> [!tip] 📸 操作提示
> 勾选 **"I accept..."**，点击 **Install**

**步骤3：等待安装完成**

安装过程通常需要2-5分钟，你会看到进度条：

> [!tip] 📸 操作提示
> 等待安装完成（约2-5分钟），显示 **"Installation complete"**

安装过程中会自动完成以下操作：
- 解压SDK文件到系统目录
- 配置环境变量（PATH）
- 注册.NET运行时
- 安装必要的组件

**步骤4：安装完成**

看到以下界面说明安装成功了！

> [!tip] 📸 操作提示
> 点击 **"Finish"** 关闭安装程序

点击 **"完成"** 按钮，安装程序会自动关闭。

### 五、验证安装是否成功

安装完成后，必须验证是否正确安装。这是排查问题的关键步骤！

#### 方法1：使用命令行验证（推荐）

1. 按 `Win + R` 键，输入 `powershell`，按回车打开PowerShell
   或者：按 `Win` 键，搜索 "PowerShell"，点击打开

2. 输入以下命令并按回车：

```bash
dotnet --version
```

**成功的输出示例：**
```
8.0.401
```

> [!tip] 📸 操作提示
> 打开 PowerShell，输入 `dotnet --version`，应显示 `8.0.xxx`

3. 再输入一个命令查看更详细的信息：

```bash
dotnet --info
```

你会看到详细的安装信息，包括：
- .NET SDK版本
- 运行时信息
- 安装路径
- 已安装的工作负载

**输出示例片段：**
```
.NET SDK:
 Version:           8.0.401
 Commit:            8a7ea83f5d

Runtime Environment:
 OS Name:     Windows
 OS Version:  10.0.22631.0
 Platform:    Win32NT

.NET workloads installed:
 There are no installed workloads.
 ...
```

> [!tip] 📸 操作提示
> 输入 `dotnet --info` 查看 SDK 版本、运行时、平台等完整信息

#### 方法2：检查环境变量

1. 右键 **"此电脑"** → **属性**
2. 点击 **"高级系统设置"**
3. 点击 **"环境变量"** 按钮
4. 在 **"系统变量"** 中找到 **Path**，双击编辑
5. 查看是否包含 `.NET` 相关路径，例如：
   - `C:\Program Files\dotnet\`

> [!tip] 📸 操作提示
> 按 `Win+S` 搜索 **"环境变量"** → 编辑系统 Path → 确认包含 dotnet 路径

### 六、常见安装选项说明

安装程序提供了一些高级选项，新手可以了解但不一定要修改：

| 选项 | 说明 | 建议 |
|------|------|------|
| **安装路径** | 默认安装在 `C:\Program Files\dotnet\` | 保持默认即可 |
| **添加到PATH** | 自动配置环境变量 | ✅ 必须勾选 |
| **Telemetry** | 发送使用数据给微软 | 可选，帮助改进产品 |

## ❓ 常见问题排查

### Q1：执行dotnet命令提示"无法识别"怎么办？

**A：** 这通常是环境变量问题，按以下步骤解决：

1. **重启电脑** - 最简单的方法，重启后环境变量生效
2. **手动检查PATH**：
   - 打开环境变量设置
   - 确认 `C:\Program Files\dotnet\` 已添加到Path中
3. **重新安装** - 如果以上方法都不行，卸载后重新安装SDK

### Q2：安装过程中报错"需要.NET Framework"?

**A：** .NET SDK安装程序可能会自动安装依赖组件。如果遇到错误：
1. 确保Windows Update已更新到最新版本
2. 手动安装 [.NET Desktop Runtime](https://dotnet.microsoft.com/download/dotnet)
3. 以管理员身份重新运行安装程序

### Q3：可以同时安装多个版本的.NET SDK吗？

**A：** 可以！而且这在实际开发中很常见。不同项目可能依赖不同版本的.NET：
- 安装新版本不会覆盖旧版本
- 使用 `dotnet --version` 显示的是默认版本
- 项目可以通过 `target framework` 指定使用的版本

### Q4：下载速度很慢怎么办？

**A：** 国内下载慢的解决方案：

1. **使用镜像源**（推荐）：
   ```bash
   # 设置临时环境变量使用镜像
   $env:DOTNET_CLI_TELEMETRY_OPTOUT=1
   ```

2. **使用代理工具**（如果有）

3. **离线安装**：在其他网络好的地方下载安装包，拷贝过来安装

### Q5：应该安装.NET Runtime还是.NET SDK？

**A：** 对于开发者来说，**必须安装 .NET SDK**！区别如下：
- **.NET Runtime**：只能运行已编译的程序，不能开发
- **.NET SDK**：包含Runtime + 开发工具，既可以运行也可以开发

### Q6：安装失败如何彻底清理重装？

**A：** 完整清理步骤：

1. 通过"设置→应用"卸载所有.NET相关程序
2. 删除残留文件夹：`C:\Program Files\dotnet\`
3. 清理用户目录下的缓存：`%USERPROFILE%\.dotnet\`
4. 重启电脑
5. 重新下载安装包进行安装
