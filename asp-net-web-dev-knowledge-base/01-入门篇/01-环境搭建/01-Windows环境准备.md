## 💡 核心内容

### 一、为什么需要关注系统配置？

在开始学习ASP.NET Core之前，确保你的电脑满足基本要求非常重要。就像盖房子需要先打好地基一样，良好的开发环境是高效编程的基础。如果电脑配置过低，可能会遇到以下问题：
- 编译速度慢，等待时间长
- 运行程序时卡顿或崩溃
- 同时运行多个工具时内存不足
- IDE（集成开发环境）响应迟缓

### 二、最低系统要求

| 配置项 | 最低要求 | 说明 |
|--------|----------|------|
| **操作系统** | Windows 10 (64位) 或 Windows 11 | 必须是64位版本，32位不支持现代.NET |
| **处理器(CPU)** | 1.8 GHz 双核以上 | 推荐四核及以上，支持虚拟化技术更佳 |
| **内存(RAM)** | 8 GB | 开发时IDE+浏览器+数据库会占用大量内存 |
| **硬盘空间** | 20 GB 可用空间 | 安装SDK、工具、项目文件都需要空间 |
| **显示器分辨率** | 1280×768 以上 | 分辨率太低会影响代码阅读体验 |

### 三、推荐配置（更流畅的开发体验）

如果你希望开发过程更加顺畅，强烈推荐以下配置：

| 配置项 | 推荐配置 | 优势说明 |
|--------|----------|----------|
| **操作系统** | Windows 11 最新版 | 更好的性能优化和安全更新 |
| **处理器(CPU)** | Intel i5/i7 或 AMD Ryzen 5/7 | 多核处理能力让编译更快 |
| **内存(RAM)** | 16 GB 或更高 | 可以同时运行多个项目和虚拟机 |
| **硬盘** | SSD固态硬盘 + 50GB空间 | 项目加载速度快5-10倍 |
| **网络** | 稳定的宽带连接 | 需要下载SDK包和NuGet依赖包 |

> **💡 小贴士：** 如果你是学生或预算有限，8GB内存的电脑完全可以胜任入门阶段的学习。等熟悉之后再考虑升级硬件也不迟。

### 四、如何检查你的电脑配置？

#### 方法1：通过"此电脑"快速查看

1. 打开**文件资源管理器**
2. 在左侧导航栏点击**"此电脑"**
3. 你会看到各个磁盘的剩余空间

> [!tip] 📸 操作提示
> 打开**文件资源管理器** → 左侧导航栏点击**"此电脑"** → 查看各磁盘剩余空间，确认 **C 盘至少有 10GB 可用空间**

#### 方法2：通过系统信息详细查看

1. 按 `Win + R` 键打开"运行"对话框
2. 输入 `msinfo32` 并按回车
3. 弹出"系统信息"窗口，可以看到完整配置

```

```

#### 方法3：使用命令行快速检查

打开 PowerShell 或命令提示符，输入以下命令：

```powershell
# 查看系统基本信息
systeminfo | Select-String "OS Name","Total Physical Memory"

# 查看磁盘空间
wmic logicaldisk get size,freespace,caption
```

**输出示例：**
```
OS Name:                   Microsoft Windows 11 Pro
Total Physical Memory:     16,384 MB

Caption  FreeSpace      Size
C:       85,934,751,744  256,030,531,584
D:       200,123,699,200  512,000,000,000
```

### 五、Windows系统优化建议

为了让开发体验更好，建议进行以下设置：

#### 1. 启用开发者模式（可选但推荐）

1. 打开 **设置** → **隐私和安全性** → **开发者选项**
2. 开启 **"开发人员模式"**

> [!tip] 📸 操作提示
> 打开 **设置** → **隐私和安全性** → **开发者选项** → 开启 **"开发人员模式"** 开关

#### 2. 关闭不必要的启动项

1. 按 `Ctrl + Shift + Esc` 打开任务管理器
2. 切换到 **"启动"** 选项卡
3. 右键禁用不需要开机自启的程序

#### 3. 确保Windows Update已更新到最新版本

1. 打开 **设置** → **Windows Update**
2. 点击 **"检查更新"** 并安装所有可用更新

### 六、环境检查清单 ✅

在继续下一节教程前，请逐项确认：

- [ ] 操作系统是 Windows 10/11 64位版本
- [ ] 内存至少 8GB（推荐16GB）
- [ ] C盘剩余空间至少 20GB（推荐30GB+）
- [ ] 处理器主频 1.8GHz 以上
- [ ] 已连接互联网（用于下载安装包）
- [ ] 具有管理员权限（可以安装软件）
- [ ] Windows Update 已更新到最新版本

## ❓ 常见问题排查

### Q1：我的电脑只有4GB内存怎么办？
**A：** 虽然不推荐，但如果暂时无法升级硬件，可以：
- 关闭所有不必要的后台程序
- 使用轻量级代码编辑器（如VSCode而非Visual Studio完整版）
- 避免同时运行多个大型应用程序
- 建议尽快升级到8GB以上内存

### Q2：C盘空间不足怎么清理？
**A：** 可以尝试以下方法：
1. 使用Windows自带的"磁盘清理"工具
2. 清空回收站
3. 卸载不常用的软件
4. 将大型文件移动到其他分区
5. 考虑使用外接存储设备

### Q3：如何确认我的Windows是64位还是32位？
**A：** 
- 方法1：右键"此电脑"→属性，查看"系统类型"
- 方法2：按 `Win + R`，输入 `msinfo32`，查看"系统类型"
- 如果显示"x64-based PC"就是64位

### Q4：必须使用Windows 11吗？Windows 10可以吗？
**A：** 完全可以使用Windows 10！Windows 10和11都完全支持ASP.NET Core开发。Windows 11只是有更好的性能优化和新功能，但并非必需。

### Q5：Mac电脑可以按照这个教程吗？
**A：** 本教程专门针对Windows用户。如果你使用Mac，请参考macOS版本的教程。好消息是.NET SDK本身是跨平台的，只是操作系统的具体步骤会有所不同。
