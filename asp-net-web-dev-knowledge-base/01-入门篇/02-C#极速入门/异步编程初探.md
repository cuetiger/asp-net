## 一、为什么需要异步编程？

### 1.1 一个生活中的场景 - 点外卖

让我们用一个最贴近生活的例子来理解同步 vs 异步：

#### 同步方式（传统做法）：
```
你 → 去餐厅点餐
    → 站在柜台前等30分钟（期间什么都不能做）
    → 拿到外卖
    → 回家吃饭

问题：等待的30分钟完全浪费了！你本可以刷手机、看书、工作...
```

#### 异步方式（现代做法）：
```
你 → 在手机APP上下单（发起异步操作）
    → 继续做自己的事（看视频、工作...）
    ← 外卖员打电话："您的外卖到了"（回调通知）
    → 去拿外卖

优势：等待时间没有被浪费，你可以同时做多件事！
```

### 1.2 程序中的真实场景

在Web开发中，你的程序经常需要等待外部资源：

| 操作 | 大约耗时 | 如果同步会怎样？ |
|------|----------|------------------|
| 查询数据库 | 10-200ms | 整个服务器卡住，无法处理其他请求 |
| 调用第三方API | 100-2000ms | 用户看到页面"转圈圈"，体验极差 |
| 读写文件 | 5-50ms | 文件IO阻塞线程 |
| 发送邮件 | 500-3000ms | 邮件发送期间页面无响应 |
| 下载文件 | 不定 | 大文件下载时整个应用卡死 |

**关键问题**：如果同时有100个用户访问你的网站，每个请求都要等待数据库查询2秒...

- **同步模式**：需要100个线程同时等待 = **服务器崩溃或响应极慢**
- **异步模式**：几个线程就能处理所有请求 = **高效利用资源**

### 1.3 形象比喻对比

```csharp
// ===== 同步代码 =====
public void ProcessOrder_Sync()
{
    Console.WriteLine("1. 接收订单");

    Console.WriteLine("2. 查询库存（等待2秒）...");
    Thread.Sleep(2000);  // 模拟数据库查询 - 主线程被阻塞！

    Console.WriteLine("3. 扣减库存（等待1秒）...");
    Thread.Sleep(1000);  // 模拟数据库更新 - 继续阻塞！

    Console.WriteLine("4. 发送确认邮件（等待3秒）...");
    Thread.Sleep(3000);  // 模拟发送邮件 - 还在阻塞！

    Console.WriteLine("5. 订单处理完成");
    // 总耗时: 6秒，这6秒内这个线程什么都干不了！
}

// ===== 异步代码 =====
public async Task ProcessOrder_Async()
{
    Console.WriteLine("1. 接收订单");

    Console.WriteLine("2. 查询库存（异步）...");
    await Task.Delay(2000);  // 模拟异步数据库查询 - 线程可以去处理其他请求！

    Console.WriteLine("3. 扣减库存（异步）...");
    await Task.Delay(1000);  // 模拟异步数据库更新 - 继续不阻塞！

    Console.WriteLine("4. 发送确认邮件（异步）...");
    await Task.Delay(3000);  // 模拟异步发送邮件 - 还是不会阻塞！

    Console.WriteLine("5. 订单处理完成");
    // 总耗时还是6秒，但期间线程可以服务成千上万个其他请求！
}
```

## 二、核心概念详解

### 2.1 async 和 await 关键字

这是C#中实现异步编程的两个最重要的关键字：

```csharp
// async: 标记方法为异步方法
// await: 等待异步操作完成（但不阻塞线程）

public async Task<string> GetDataAsync()
{
    Console.WriteLine("开始获取数据...");

    // await: 到这里时，方法会"暂停"并返回给调用者
    // 但底层线程不会被阻塞，可以去干别的事！
    string result = await HttpClient.GetStringAsync("https://api.example.com/data");

    // 当数据返回后，从这里继续执行
    Console.WriteLine("数据获取完成！");
    return result;
}
```

#### 关键要点：

| 关键字 | 位置 | 作用 |
|--------|------|------|
| `async` | 方法签名前 | 告诉编译器这是一个异步方法，方法内部可以使用`await` |
| `await` | 异步调用前 | **暂停**当前方法的执行，等待操作完成，但不占用线程 |

### 2.2 Task类 - 异步操作的载体

`Task`代表一个**异步操作**，类似于一个"承诺将来会完成的任务"。

#### Task的基本类型：

```csharp
// Task: 表示没有返回值的异步操作（类似void）
public async Task DoSomethingAsync()
{
    await Task.Delay(1000);
    Console.WriteLine("完成了！");
}

// Task<T>: 表示有返回值的异步操作
public async Task<int> CalculateAsync()
{
    await Task.Delay(500);
    return 42;  // 返回int类型的结果
}

// ValueTask<T>: 高性能场景下使用（可复用内存）
public async ValueTask<string> GetValueAsync()
{
    return "Hello";
}
```

### 2.3 完整示例：从零开始理解异步流程

```csharp
public class AsyncBasicsDemo
{
    public async Task DemonstrateAsyncFlow()
    {
        Console.WriteLine("=== 异步流程演示 ===\n");
        Console.WriteLine($"[主线程] 线程ID: {Thread.CurrentThread.ManagedThreadId}");
        Console.WriteLine("[主线程] 开始调用异步方法...\n");

        // 调用异步方法
        Task<string> task = LongRunningOperationAsync();  // 注意：这里并没有等待！

        Console.WriteLine("[主线程] 异步方法已启动，但我继续执行其他工作...\n");

        // 主线程可以继续做其他事情
        DoOtherWork();

        Console.WriteLine("\n[主线程] 现在需要用到异步结果了，开始await...\n");

        // await: 如果任务还没完成，就等待；如果已完成，立即得到结果
        string result = await task;

        Console.WriteLine($"\n[主线程] 收到结果: {result}");
        Console.WriteLine($"[主线程] 最终线程ID: {Thread.CurrentThread.ManagedThreadId}");
    }

    private async Task<string> LongRunningOperationAsync()
    {
        Console.WriteLine($"[异步方法] 开始执行，线程ID: {Thread.CurrentThread.ManagedThreadId}");
        Console.WriteLine("[异步方法] 模拟耗时操作（3秒）...");

        // Task.Delay是异步版本的Thread.Sleep
        // await期间，这个线程会被释放去做别的事！
        await Task.Delay(3000);

        Console.WriteLine($"[异步方法] 操作完成，线程ID: {Thread.CurrentThread.ManagedThreadId}");

        return "操作成功完成的数据";
    }

    private void DoOtherWork()
    {
        Console.WriteLine("--- [主线程] 正在做其他工作 ---");
        for (int i = 1; i <= 3; i++)
        {
            Console.WriteLine($"  处理任务{i}...");
            Thread.Sleep(200);  // 模拟短暂的工作
        }
        Console.WriteLine("--- [主线程] 其他工作完成 ---\n");
    }
}

// 运行演示
var demo = new AsyncBasicsDemo();
await demo.DemonstrateAsyncFlow();
```

### 3.1 场景1：异步HTTP请求

```csharp
using System.Net.Http;

public class WebApiClient
{
    private readonly HttpClient _httpClient;

    public WebApiClient()
    {
        _httpClient = new HttpClient();
        _httpClient.Timeout = TimeSpan.FromSeconds(30);
    }

    /// <summary>
    /// 异步获取用户信息
    /// </summary>
    public async Task<UserInfo> GetUserAsync(int userId)
    {
        try
        {
            string url = $"https://api.example.com/users/{userId}";

            Console.WriteLine($"[API] 开始请求: GET {url}");

            // 异步发送HTTP GET请求
            HttpResponseMessage response = await _httpClient.GetAsync(url);

            response.EnsureSuccessStatusCode();  // 如果状态码不是2xx则抛异常

            // 异步读取响应内容（作为字符串）
            string json = await response.Content.ReadAsStringAsync();

            Console.WriteLine($"[API] 响应成功，长度: {json.Length} 字符");

            // 解析JSON（实际项目中会用Newtonsoft.Json或System.Text.Json）
            var user = ParseUserJson(json);

            return user;
        }
        catch (HttpRequestException ex)
        {
            Console.WriteLine($"[API] HTTP错误: {ex.Message}");
            throw;  // 重新抛出，让调用者处理
        }
        catch (TaskCanceledException)
        {
            Console.WriteLine("[API] 请求超时！");
            throw new TimeoutException("API请求超时");
        }
    }

    /// <summary>
    /// 异步创建订单
    /// </summary>
    public async Task<OrderResult> CreateOrderAsync(OrderRequest order)
    {
        string url = "https://api.example.com/orders";

        // 序列化对象为JSON
        string jsonContent = System.Text.Json.JsonSerializer.Serialize(order);

        Console.WriteLine($"[API] 创建订单: {jsonContent.Substring(0, Math.Min(50, jsonContent.Length))}...");

        using (var content = new StringContent(jsonContent, Encoding.UTF8, "application/json"))
        {
            // 异步POST请求
            HttpResponseMessage response = await _httpClient.PostAsync(url, content);

            response.EnsureSuccessStatusCode();

            string responseJson = await response.Content.ReadAsStringAsync();

            var result = System.Text.Json.JsonSerializer.Deserialize<OrderResult>(responseJson);

            Console.WriteLine($"[API] 订单创建成功! ID: {result?.OrderId}");

            return result;
        }
    }

    /// <summary>
    /// 并行获取多个用户信息
    /// </summary>
    public async Task<List<UserInfo>> GetUsersBatchAsync(List<int> userIds)
    {
        Console.WriteLine($"\n[批量] 开始获取 {userIds.Count} 个用户信息...");

        DateTime startTime = DateTime.Now;

        // 方式1：顺序执行（慢）
        // var users = new List<UserInfo>();
        // foreach (var id in userIds)
        // {
        //     var user = await GetUserAsync(id);  // 一个接一个
        //     users.Add(user);
        // }

        // 方式2：并行执行（快！）- 使用Task.WhenAll
        var tasks = userIds.Select(id => GetUserAsync(id)).ToArray();

        // 同时发起所有请求，等待全部完成
        UserInfo[] results = await Task.WhenAll(tasks);

        TimeSpan elapsed = DateTime.Now - startTime;

        Console.WriteLine($"[批量] 全部完成! 耗时: {elapsed.TotalSeconds:F2}秒");
        Console.WriteLine($"[批量] 成功获取 {results.Length} 个用户信息\n");

        return results.ToList();
    }


    // 辅助类和方法（简化示例用）
    public class UserInfo
    {
        public int Id { get; set; }
        public string Name { get; set; }
        public string Email { get; set; }
    }

    public class OrderRequest
    {
        public int UserId { get; set; }
        public decimal Amount { get; set; }
        public List<OrderItem> Items { get; set; }
    }

    public class OrderItem
    {
        public int ProductId { get; set; }
        public int Quantity { get; set; }
    }

    public class OrderResult
    {
        public int OrderId { get; set; }
        public string Status { get; set; }
        public DateTime CreatedAt { get; set; }
    }

    private UserInfo ParseUserJson(string json) =>
        System.Text.Json.JsonSerializer.Deserialize<UserInfo>(json);
}
```

```csharp
using Microsoft.EntityFrameworkCore;

/// <summary>
/// 异步仓储模式示例
/// </summary>
public class UserRepository
{
    private readonly AppDbContext _context;

    public UserRepository(AppDbContext context)
    {
        _context = context;
    }

    /// <summary>
    /// 异步根据ID查找用户
    /// </summary>
    public async Task<User> GetByIdAsync(int id)
    {
        Console.WriteLine($"[DB] 查询用户 ID={id}...");

        User user = await _context.Users
            .FirstOrDefaultAsync(u => u.Id == id);  // 注意：Async版本！

        if (user != null)
            Console.WriteLine($"[DB] 找到用户: {user.Name}");
        else
            Console.WriteLine($"[DB] 未找到用户 ID={id}");

        return user;
    }

    /// <summary>
    /// 异步分页查询
    /// </summary>
    public async Task<PagedResult<User>> GetPagedAsync(int page, int pageSize)
    {
        Console.WriteLine($"[DB] 分页查询 第{page}页，每页{pageSize}条...");

        IQueryable<User> query = _context.Users
            .Where(u => u.IsActive)  // 只查活跃用户
            .OrderBy(u => u.Name);

        // 总数查询（异步）
        int totalCount = await query.CountAsync();

        // 分页查询（异步）
        var items = await query
            .Skip((page - 1) * pageSize)
            .Take(pageSize)
            .ToListAsync();

        var result = new PagedResult<User>
        {
            Items = items,
            TotalCount = totalCount,
            Page = page,
            PageSize = pageSize,
            TotalPages = (int)Math.Ceiling((double)totalCount / pageSize)
        };

        Console.WriteLine($"[DB] 查询完成: 共{totalCount}条，本页{items.Count}条");

        return result;
    }

    /// <summary>
    /// 异步添加用户
    /// </summary>
    public async Task<User> AddAsync(User user)
    {
        Console.WriteLine($"[DB] 添加用户: {user.Name}...");

        _context.Users.Add(user);

        // SaveChangesAsync是异步保存到数据库
        int affectedRows = await _context.SaveChangesAsync();

        Console.WriteLine($"[DB] 保存成功! 影响行数: {affectedRows}");

        return user;
    }

    /// <summary>
    /// 异步批量操作
    /// </summary>
    public async Task<int> UpdateLastLoginTimeAsync(IEnumerable<int> userIds)
    {
        var users = await _context.Users
            .Where(u => userIds.Contains(u.Id))
            .ToListAsync();

        foreach (var user in users)
        {
            user.LastLoginTime = DateTime.UtcNow;
        }

        return await _context.SaveChangesAsync();
    }
}
```

### 3.3 场景3：异步文件操作

```csharp
using System.IO;

public class FileProcessor
{
    /// <summary>
    /// 异步读取日志文件并分析
    /// </summary>
    public async Task<List<LogEntry>> ReadLogAsync(string filePath)
    {
        Console.WriteLine($"[文件] 开始读取: {Path.GetFileName(filePath)}");

        // 异步读取全部文本
        string content = await File.ReadAllTextAsync(filePath);

        Console.WriteLine($"[文件] 读取完成，大小: {content.Length} 字符");

        // 解析日志
        var entries = ParseLogs(content);

        Console.WriteLine($"[文件] 解析出 {entries.Count} 条日志记录");

        return entries;
    }

    /// <summary>
    /// 异步写入报告
    /// </summary>
    public async Task WriteReportAsync(string filePath, ReportData data)
    {
        Console.WriteLine($"[文件] 生成报告...");

        string content = GenerateReportContent(data);

        // 异步写入文件
        await File.WriteAllTextAsync(filePath, content);

        Console.WriteLine($"[文件] 报告已保存: {filePath}");
        Console.WriteLine($"[文件] 文件大小: {new FileInfo(filePath).Length} 字节");
    }

    /// <summary>
    /// 异步复制大文件（带进度）
    /// </summary>
    public async Task CopyFileWithProgressAsync(string sourcePath, string destPath,
                                               IProgress<long> progress = null)
    {
        const int bufferSize = 81920; // 80KB缓冲区

        var fileInfo = new FileInfo(sourcePath);
        long totalBytes = fileInfo.Length;
        long bytesCopied = 0;

        Console.WriteLine($"\n[复制] 开始: {fileInfo.Name:N0} 字节");

        using (FileStream source = new FileStream(sourcePath, FileMode.Open, FileAccess.Read))
        using (FileStream dest = new FileStream(destPath, FileMode.Create, FileAccess.Write))
        {
            byte[] buffer = new byte[bufferSize];
            int bytesRead;

            while ((bytesRead = await source.ReadAsync(buffer, 0, buffer.Length)) > 0)
            {
                await dest.WriteAsync(buffer, 0, bytesRead);

                bytesCopied += bytesRead;

                // 报告进度
                progress?.Report(bytesCopied);

                double percent = (double)bytesCopied / totalBytes * 100;

                if (percent % 10 < 1)  // 每10%打印一次
                {
                    string bar = new string('█', (int)(percent / 2.5));
                    Console.WriteLine($"\r[复制] 进度: [{bar,-40}] {percent:F1}%");
                }
            }
        }

        Console.WriteLine($"\n[复制] 完成! 已复制 {bytesCopied:N0} 字节");
    }

    // 辅助成员
    public class LogEntry
    {
        public DateTime Timestamp { get; set; }
        public string Level { get; set; }
        public string Message { get; set; }
    }

    public class ReportData
    {
        public string Title { get; set; }
        public Dictionary<string, object> Data { get; set; } = new();
        public DateTime GeneratedAt { get; set; } = DateTime.Now;
    }

    private List<LogEntry> ParseLogs(string content)
    {
        // 简化解析逻辑
        return content.Split('\n')
            .Where(line => !string.IsNullOrWhiteSpace(line))
            .Select((line, index) => new LogEntry
            {
                Timestamp = DateTime.Now.AddSeconds(-index),
                Level = "INFO",
                Message = line.Trim()
            })
            .ToList();
    }

    private string GenerateReportContent(ReportData data)
    {
        var sb = new System.Text.StringBuilder();
        sb.AppendLine($"# {data.Title}");
        sb.AppendLine($"生成时间: {data.GeneratedAt:yyyy-MM-dd HH:mm:ss}");
        sb.AppendLine();
        foreach (var item in data.Data)
        {
            sb.AppendLine($"{item.Key}: {item.Value}");
        }
        return sb.ToString();
    }
}
```

## 四、进阶用法与最佳实践

### 4.1 并行执行多个异步任务

```csharp
public class ParallelAsyncDemo
{
    public async Task DemonstrateParallelExecution()
    {
        Console.WriteLine("=== 并行异步执行演示 ===\n");
        Stopwatch sw = Stopwatch.StartNew();

        // 任务1：获取用户信息
        Task<string> userTask = FetchUserDataAsync("user123");

        // 任务2：获取产品列表
        Task<string> productsTask = FetchProductsAsync();

        // 任务3：获取推荐内容
        Task<string> recommendationsTask = FetchRecommendationsAsync("user123");

        Console.WriteLine("三个请求已同时发出...\n");

        // 使用WhenAll等待所有任务完成
        await Task.WhenAll(userTask, productsTask, recommendationsTask);

        sw.Stop();

        Console.WriteLine($"\n✓ 所有任务完成!");
        Console.WriteLine($"  用户数据长度: {userTask.Result.Length}");
        Console.WriteLine($"  产品数据长度: {productsTask.Result.Length}");
        Console.WriteLine($"  推荐数据长度: {recommendationsTask.Result.Length}");
        Console.WriteLine($"  总耗时: {sw.ElapsedMilliseconds}ms (如果是串行会更久)");
    }

    // WhenAny：只要有一个完成就继续
    public async Task DemonstrateWhenAny()
    {
        Console.WriteLine("\n=== WhenAny 示例 ===\n");

        var tasks = new[]
        {
            FetchFromServerA(),
            FetchFromServerB(),
            FetchFromServerC()
        };

        Console.WriteLine("向3个服务器发起请求，谁先回来用谁的...\n");

        // 等待任意一个完成
        Task<string> completedTask = await Task.WhenAny(tasks);

        string fastestResult = await completedTask;  // 获取最快的结果

        Console.WriteLine($"✓ 最快的响应来自某个服务器，数据长度: {fastestResult.Length}");
    }

    // 模拟API调用
    private async Task<string> FetchUserDataAsync(string userId)
    {
        Console.WriteLine("[→] 开始获取用户数据...");
        await Task.Delay(Random.Shared.Next(1000, 2000));  // 模拟1-2秒延迟
        Console.WriteLine("[←] 用户数据获取完成");
        return $"{{\"userId\":\"{userId}\", \"name\":\"张三\", ...}}";
    }

    private async Task<string> FetchProductsAsync()
    {
        Console.WriteLine("[→] 开始获取产品列表...");
        await Task.Delay(Random.Shared.Next(800, 1500));
        Console.WriteLine("[←] 产品列表获取完成");
        return "[{\"id\":1,\"name\":\"iPhone\"}, ...]";
    }

    private async Task<string> FetchRecommendationsAsync(string userId)

        Console.WriteLine("[→] 开始获取推荐内容...");
        await Task.Delay(Random.Shared.Next(1200, 2500));
        Console.WriteLine("[←] 推荐内容获取完成");
        return "[{\"type\":\"product\",\"id\":101}, ...]";
    }

    private async Task<string> FetchFromServerA() { await Task.Delay(1000); return "Server A"; }
    private async Task<string> FetchFromServerB() { await Task.Delay(2500); return "Server B"; }
    private async Task<string> FetchFromServerC() { await Task.Delay(1800); return "Server C"; }
```

### 4.2 错误处理与超时控制

```csharp
public class RobustAsyncDemo
{
    /// <summary>
    /// 带重试机制的异步操作
    /// </summary>
    public async Task<T> WithRetryAsync<T>(Func<Task<T>> operation,
                                           int maxRetries = 3,
                                           TimeSpan? delay = null)
    {
        delay ??= TimeSpan.FromSeconds(1);

        for (int attempt = 1; attempt <= maxRetries; attempt++)
        {
            try
            {
                Console.WriteLine($"[重试] 第 {attempt}/{maxRetries} 次尝试...");

                T result = await operation();

                Console.WriteLine($"[重试] ✓ 成功！(第{attempt}次尝试)");
                return result;
            }
            catch (Exception ex) when (attempt < maxRetries)
            {
                Console.WriteLine($"[重试] ✗ 失败: {ex.Message}");
                Console.WriteLine($"[重试] 等待 {delay.Value.TotalSeconds}秒后重试...");

                await Task.Delay(delay.Value);
            }
        }

        throw new Exception($"操作在{maxRetries}次尝试后仍然失败");
    }

    /// <summary>
    /// 带超时的异步操作
    /// </summary>
    public async Task<T> WithTimeoutAsync<T>(Func<Task<T>> operation,
                                            TimeSpan timeout)
    {
        Console.WriteLine($"[超时] 设置超时: {timeout.TotalSeconds}秒");

        using var cts = new CancellationTokenSource(timeout);

        try
        {
            // 创建带取消令牌的任务
            Task<T> taskWithTimeout = Task.Run(async () =>
            {
                // 将CancellationToken传递给支持取消的操作
                return await operation();
            }, cts.Token);

            T result = await taskWithTimeout;

            Console.WriteLine("[超时] ✓ 在超时时间内完成");
            return result;
        }
        catch (OperationCanceledException)
        {
            Console.WriteLine($"[超时] ✗ 操作超时 ({timeout.TotalSeconds}秒)");
            throw new TimeoutException($"操作在 {timeout.TotalSeconds}秒 内未完成");
        }
    }

    /// <summary>
    /// 组合使用：重试 + 超时
    /// </summary>
    public async Task<string> RobustApiCallAsync(string url)
    {
        Console.WriteLine("\n=== 健壮的API调用 ===\n");

        // 外层：重试机制
        return await WithRetryAsync(async () =>
        {
            // 内层：单次调用的超时控制
            return await WithTimeoutAsync(async () =>
            {
                Console.WriteLine($"[API] 请求: {url}");

                // 模拟网络请求（随机失败或超时）
                await Task.Delay(Random.Shared.Next(100, 3000));

                if (Random.Shared.NextDouble() < 0.3)  // 30%概率失败
                    throw new HttpRequestException("模拟网络错误");

                return $"{{\"status\":\"ok\",\"data\":\"从{url}获取的数据\"}}";

            }, TimeSpan.FromSeconds(2));  // 单次超时2秒

        }, maxRetries: 3);  // 最多重试3次
    }
```

```csharp
public class AsyncPitfallsDemo
{
    // ❌ 陷阱1：async void - 只用于事件处理器
    public async void BadAsyncVoid()  // 不要这样写！
    {
        await Task.Delay(1000);
        // 异常会被吞掉，调用者无法捕获！
    }

    // ✅ 正确：使用async Task
    public async Task GoodAsyncTask()
    {
        await Task.Delay(1000);
        // 异常可以被正确传播
    }

    // ❌ 陷阱2：在非异步上下文中使用.Result或.Wait() - 可能死锁！
    public void BlockingCall()
    {
        // 危险！可能导致死锁
        // var result = SomeAsyncMethod().Result;      // 不要这样做
        // SomeAsyncMethod().Wait();                    // 不要这样做

        // 如果必须在同步方法中调用异步方法：
        var result = SomeAsyncMethod().GetAwaiter().GetResult();  // 相对安全但仍不推荐
    }

    private async Task<string> SomeAsyncMethod()
    {
        await Task.Delay(100);
        return "done";
    }

    // ❌ 陷阱3：忘记await - 静默忽略异常
    public async Task FireAndForgetBad()
    {
        // 忘记await，异常会被静默忽略
        _ = DangerousOperationAsync();  // 如果这个抛异常，你永远不知道！

        Console.WriteLine("继续执行...");
    }

    // ✅ 正确：使用专门的Fire-and-forget方法
    public async Task FireAndForgetGood()
    {
        _ = FireAndForgetSafeAsync(DangerousOperationAsync());

        Console.WriteLine("继续执行...");
    }

    private async Task FireAndForgetSafeAsync(Task task)
    {
        try
        {
            await task;
        }
        catch (Exception ex)
        {
            Console.WriteLine($"[后台任务] 发生异常（已被捕获）: {ex.Message}");
            // 记录日志、发送告警等
        }
    }

    private async Task DangerousOperationAsync()
    {
        await Task.Delay(100);
        throw new InvalidOperationException("模拟异常！");
    }

    // ❌ 陷阱4：在循环中使用await而不并行
    public async Task SequentialVsParallel()
    {
        var ids = Enumerable.Range(1, 5).ToList();

        Console.WriteLine("=== 串行 vs 并行对比 ===\n");

        // 串行（慢）：总耗时 = 所有时间之和
        Stopwatch sw = Stopwatch.StartNew();
        Console.WriteLine("[串行] 开始:");
        foreach (var id in ids)
        {
            await ProcessItemAsync(id);  // 一个接一个
        }
        Console.WriteLine($"[串行] 完成! 耗时: {sw.ElapsedMilliseconds}ms\n");

        // 并行（快）：总耗时 ≈ 最慢的那个
        sw.Restart();
        Console.WriteLine("[并行] 开始:");
        var tasks = ids.Select(id => ProcessItemAsync(id)).ToArray();
        await Task.WhenAll(tasks);
        Console.WriteLine($"[并行] 完成! 耗时: {sw.ElapsedMilliseconds}ms");
    }

    private async Task ProcessItemAsync(int id)
    {
        Console.WriteLine($"  处理项目 {id}...");
        await Task.Delay(Random.Shared.Next(500, 1500));
        Console.WriteLine($"  项目 {id} 完成");
    }
}
```

```csharp
        IProductService productService,

    /// <summary>
    /// 创建订单（完整流程）
    /// </summary>
    public async Task<OrderResult> CreateOrderAsync(OrderRequest request)
    {
        Stopwatch sw = Stopwatch.StartNew();
        Guid orderId = Guid.NewGuid();

        Console.WriteLine($"\n{'=',60}");
        Console.WriteLine($"  🛒 开始处理订单: {orderId:N}");
        Console.WriteLine($"  客户: {request.CustomerId}");
        Console.WriteLine($"  商品数量: {request.Items.Count}");
        Console.WriteLine($"{'=',60}\n");

        try
        {
            // 步骤1：验证商品信息（可以并行）
            Console.WriteLine("[步骤1/6] 验证商品信息...");
            var productValidationTasks = request.Items.Select(item =>
                ValidateProductAsync(item.ProductId, item.Quantity));

            var validationResults = await Task.WhenAll(productValidationTasks);

            if (validationResults.Any(v => !v.IsValid))
            {
                var invalidItem = validationResults.First(v => !v.IsValid);
                throw new BusinessException($"商品验证失败: {invalidItem.ErrorMessage}");
            }
            Console.WriteLine("[步骤1/6] ✓ 商品验证通过\n");


            // 步骤2：锁定库存（关键操作，需要事务）
            Console.WriteLine("[步骤2/6] 锁定库存...");
            InventoryReservation reservation = await _inventoryService
                .ReserveInventoryAsync(request.Items, orderId);

            Console.WriteLine($"[步骤2/6] ✓ 库存已锁定 (预留ID: {reservation.ReservationId})\n");


            // 步骤3：计算价格（依赖步骤1的结果）
            Console.WriteLine("[步骤3/6] 计算订单金额...");
            PriceCalculation priceCalc = await CalculatePriceAsync(
                request.Items,
                request.CustomerId,
                request.CouponCode);

            Console.WriteLine($"[步骤3/6] ✓ 金额计算完成");
            Console.WriteLine($"         小计: ¥{priceCalc.Subtotal:F2}");
            Console.WriteLine($"         折扣: -¥{priceCalc.Discount:F2}");
            Console.WriteLine($"         运费: ¥{priceCalc.Shipping:F2}");
            Console.WriteLine($"         总计: ¥{priceCalc.GrandTotal:F2}\n");


            // 步骤4：处理支付
            Console.WriteLine("[步骤4/6] 处理支付...");
            PaymentResult payment = await _paymentService
                .ProcessPaymentAsync(new PaymentRequest
                {
                    OrderId = orderId,
                    Amount = priceCalc.GrandTotal,
                    Currency = "CNY",
                    PaymentMethod = request.PaymentMethod,
                    CustomerId = request.CustomerId
                });

            if (!payment.IsSuccess)
            {
                // 支付失败，释放库存
                await _inventoryService.ReleaseReservationAsync(reservation.ReservationId);
                throw new BusinessException($"支付失败: {payment.ErrorMessage}");
            }
            Console.WriteLine($"[步骤4/6] ✓ 支付成功 (交易号: {payment.TransactionId})\n");


            // 步骤5：创建订单记录（持久化到数据库）
            Console.WriteLine("[步骤5/6] 保存订单...");
            Order order = await _orderRepo.CreateAsync(new Order
            {
                Id = orderId,
                CustomerId = request.CustomerId,
                Items = request.Items,
                Pricing = priceCalc,
                Payment = payment,
                ShippingAddress = request.ShippingAddress,
                Status = OrderStatus.PendingShipment,
                CreatedAt = DateTime.UtcNow
            });
            Console.WriteLine($"[步骤5/6] ✓ 订单已保存 (#{order.OrderNumber})\n");


            // 步骤6：触发后续操作（并行且不阻塞响应）
            Console.WriteLine("[步骤6/6] 触发后续操作...");
            TriggerPostOrderProcesses(order, reservation);

            sw.Stop();


            // 返回成功结果
            Console.WriteLine($"\n{'=',60}");
            Console.WriteLine($"  ✅ 订单创建成功！");
            Console.WriteLine($"  订单号: {order.OrderNumber}");
            Console.WriteLine($"  总耗时: {sw.ElapsedMilliseconds}ms");
            Console.WriteLine($"{'=',60}\n");

            return new OrderResult
            {
                Success = true,
                OrderId = orderId,
                OrderNumber = order.OrderNumber,
                TotalAmount = priceCalc.GrandTotal,
                EstimatedDelivery = DateTime.UtcNow.AddDays(3),
                ProcessingTimeMs = sw.ElapsedMilliseconds
            };
        }
        catch (BusinessException ex)
        {
            Console.WriteLine($"\n❌ 业务错误: {ex.Message}");
            return new OrderResult { Success = false, ErrorMessage = ex.Message };
        }
        catch (Exception ex)
        {
            Console.WriteLine($"\n💥 系统错误: {ex.Message}");
            // TODO: 记录日志，告警
            return new OrderResult { Success = false, ErrorMessage = "系统繁忙，请稍后重试" };
        }

    private async Task<ProductValidation> ValidateProductAsync(int productId, int quantity)
    {
        Product product = await _productService.GetByIdAsync(productId);

        if (product == null)
            return new ProductValidation { IsValid = false, ErrorMessage = $"商品{productId}不存在" };

        if (!product.IsAvailable)
            return new ProductValidation { IsValid = false, ErrorMessage = $"{product.Name}已下架" };

        if (quantity <= 0)
            return new ProductValidation { IsValid = false, ErrorMessage = "数量必须大于0" };

        if (quantity > product.MaxOrderQuantity)
            return new ProductValidation { IsValid = false, ErrorMessage = $"超出最大购买限制({product.MaxOrderQuantity})" };

        return new ProductValidation { IsValid = true, Product = product };
    }

    private async Task<PriceCalculation> CalculatePriceAsync(
        List<OrderItem> items, string customerId, string couponCode)
    {
        decimal subtotal = 0;
        decimal discount = 0;

        foreach (var item in items)
        {
            Product product = await _productService.GetByIdAsync(item.ProductId);
            subtotal += product.Price * item.Quantity;
        }

        // 应用优惠券折扣
        if (!string.IsNullOrEmpty(couponCode))
        {
            Coupon coupon = await _couponService.ValidateAsync(couponCode, customerId);
            if (coupon != null)
            {
                discount = subtotal * (coupon.DiscountPercentage / 100m);
            }
        }

        // 计算运费（简化逻辑）
        decimal shipping = subtotal >= 99 ? 0 : 15;  // 满99包邮

        return new PriceCalculation
        {
            Subtotal = subtotal,
            Discount = discount,
            Shipping = shipping,
            Tax = (subtotal - discount) * 0.13m,  // 13%增值税
            GrandTotal = subtotal - discount + shipping
        };
    }
```

## 六、总结与最佳实践

### 6.1 核心要点回顾

| 概念 | 说明 | 使用场景 |
|------|------|----------|
| `async` | 标记异步方法 | 任何包含`await`的方法 |
| `await` | 等待异步完成 | 调用异步方法时 |
| `Task` | 无返回值的异步操作 | 异步方法返回类型 |
| `Task<T>` | 有返回值的异步操作 | 需要返回数据时 |
| `Task.WhenAll` | 等待所有任务 | 并行多个独立操作 |
| `Task.WhenAny` | 等待任一任务 | 超时、竞速场景 |
| `CancellationToken` | 取消长时间操作 | 用户取消、超时控制 |

### 6.2 最佳实践清单

#### ✅ 应该做的：

- [ ] **所有I/O操作都用异步**：数据库、网络、文件、API调用
- [ ] **一直使用async向下传播**：不要混用sync和async
- [ ] **合理使用`ConfigureAwait(false)`**：库代码中避免死锁
- [ ] **并行独立操作**：用`Task.WhenAll`提升性能
- [ ] **正确处理异常**：try-catch包裹await调用
- [ ] **考虑取消令牌**：长时间运行的操作支持取消
- [ ] **添加超时控制**：避免无限等待

#### ❌ 不应该做的：

- [ ] **不要使用`async void`**（除了事件处理器）
- [ ] **不要`.Result()`或`.Wait()`**（会导致死锁风险）
- [ ] **不要在热路径上过度使用async**（简单计算不需要）
- [ ] **不要忘记`await`**（静默忽略异常和结果）
- [ ] **不要在循环中`await`**（应该用`WhenAll`并行）

### 6.3 性能对比

```
同步模式（100并发请求，每个等待100ms数据库查询）：
├── 需要100个线程
├── 线程大部分时间在等待
├── 内存占用高（每个线程约1MB栈空间）
└── 吞吐量低

异步模式（同样的场景）：
├── 只需几个线程
├── 等待时线程释放去服务其他请求
├── 内存占用极低
└── 吞吐量提升10-100倍！
```

```csharp
public class ParallelDownloader
{
    private readonly HttpClient _httpClient = new HttpClient();

    public async Task DownloadFilesAsync(List<string> urls,
                                          CancellationToken cancellationToken = default,
                                          IProgress<DownloadProgress> progress = null)
    {
        Console.WriteLine("=== 并行文件下载器 ===\n");
        Console.WriteLine($"待下载文件数: {urls.Count}\n");

        Stopwatch totalSw = Stopwatch.StartNew();

        // 为每个URL创建下载任务
        var downloadTasks = urls.Select((url, index) =>
            DownloadSingleFileAsync(url, index + 1, cancellationToken, progress))
            .ToArray();

        try
        {
            // 等待所有下载完成
            DownloadResult[] results = await Task.WhenAll(downloadTasks);

            totalSw.Stop();

            // 输出汇总
            Console.WriteLine($"\n{'=',55}");
            Console.WriteLine("  下载完成统计");
            Console.WriteLine($"{'=',55}");
            Console.WriteLine($"总文件数: {results.Length}");
            Console.WriteLine($"成功: {results.Count(r => r.Success)}");
            Console.WriteLine($"失败: {results.Count(r => !r.Success)}");
            Console.WriteLine($"总耗时: {totalSw.ElapsedMilliseconds}ms");
            Console.WriteLine($"总数据: {results.Where(r => r.Success).Sum(r => r.BytesReceived):N0} bytes");

            if (results.Any(r => r.Success && r.ElapsedMs > 0))
            {
                double avgSpeed = results.Where(r => r.Success).Average(r =>
                    (double)r.BytesReceived / r.ElapsedMs * 1000);
                Console.WriteLine($"平均速度: {avgSpeed / 1024:F2} KB/s");
            }
            Console.WriteLine($"{'=',55}\n");
        }
        catch (OperationCanceledException)
        {
            Console.WriteLine("\n⚠️  下载被用户取消！");
        }
    }

    private async Task<DownloadResult> DownloadSingleFileAsync(
        string url, int fileNumber,
        CancellationToken ct,
        IProgress<DownloadProgress> progress)
    {
        var result = new DownloadResult { Url = url, FileNumber = fileNumber };
        Stopwatch sw = Stopwatch.StartNew();

        try
        {
            Console.WriteLine($"[文件{fileNumber}] 开始下载: {ExtractFileName(url)}");

            using (var response = await _httpClient.GetAsync(url, HttpCompletionOption.ResponseHeadersRead, ct))
            {
                response.EnsureSuccessStatusCode();
                long totalBytes = response.Content.Headers.ContentLength ?? 0;
                result.BytesExpected = totalBytes;

                using (var stream = await response.Content.ReadAsStreamAsync(ct))
                using (var ms = new MemoryStream())
                {
                    byte[] buffer = new byte[81920];
                    int bytesRead;
                    long bytesReceived = 0;

                    while ((bytesRead = await stream.ReadAsync(buffer, ct)) > 0)
                    {
                        ct.ThrowIfCancellationRequested();

                        await ms.WriteAsync(buffer.AsMemory(0, bytesRead), ct);
                        bytesReceived += bytesRead;
                        result.BytesReceived = bytesReceived;

                        // 报告进度
                        progress?.Report(new DownloadProgress
                        {
                            FileNumber = fileNumber,
                            BytesReceived = bytesReceived,
                            TotalBytes = totalBytes
                        });

                        // 显示进度条（简化版，每10%更新一次）
                        if (totalBytes > 0)
                        {
                            double percent = (double)bytesReceived / totalBytes * 100;
                            if ((int)percent % 25 == 0 || bytesReceived == totalBytes)
                            {
                                string bar = new string('█', (int)(percent / 2.5));
                                Console.WriteLine($"\r[文件{fileNumber}] [{bar,-40}] {percent:F0}%");
                            }
                        }
                    }

                    result.Data = ms.ToArray();
                }
            }

            result.Success = true;
            sw.Stop();
            result.ElapsedMs = (int)sw.ElapsedMilliseconds;

            double speed = (double)result.BytesReceived / result.ElapsedMs * 1000;
            Console.WriteLine($"[文件{fileNumber}] ✓ 完成! {result.BytesReceived:N0} bytes, " +
                           $"{result.ElapsedMs}ms, {speed / 1024:F2} KB/s");
        }
        catch (OperationCanceledException)
        {
            result.Success = false;
            result.ErrorMessage = "已取消";
            Console.WriteLine($"[文件{fileNumber}] ✗ 下载已取消");
        }
        catch (Exception ex)
        {
            result.Success = false;
            result.ErrorMessage = ex.Message;
            Console.WriteLine($"[文件{fileNumber}] ✗ 错误: {ex.Message}");
        }

        return result;
    }

    {
        try
        {
            return new Uri(url).Segments.LastOrDefault() ?? "unknown";
        }
        catch
        {
            return "unknown";
        }
    }

        public long BytesReceived { get; set; }
        public long BytesExpected { get; set; }
        public int ElapsedMs { get; set; }
        public string ErrorMessage { get; set; }
        public byte[] Data { get; set; }
    }

        public int FileNumber { get; set; }
        public long BytesReceived { get; set; }
        public long TotalBytes { get; set; }
    }
```

**题目**：实现一个健壮的API客户端类，具备以下功能：

<details>
<summary>查看答案</summary>

```csharp
public class ResilientApiClient
{
    private readonly HttpClient _httpClient;
    private readonly ILogger _logger;
    private readonly MemoryCache _cache;
    private readonly SemaphoreSlim _rateLimiter;

    public int MaxRetries { get; set; } = 3;
    public TimeSpan RetryDelay { get; set; } = TimeSpan.FromSeconds(1);
    public TimeSpan DefaultTimeout { get; set; } = TimeSpan.FromSeconds(30);
    public int MaxRequestsPerSecond { get; set; } = 10;


    public ResilientApiClient(ILogger logger = null)
    {
        _httpClient = new HttpClient();
        _logger = logger ?? new ConsoleLogger();
        _cache = new MemoryCache(new MemoryCacheOptions
        {
            SizeLimit = 100,
            CompactionPercentage = 0.2
        });

        // 限速器：每秒最多MaxRequestsPerSecond个请求
        _rateLimiter = new SemaphoreSlim(MaxRequestsPerSecond, MaxRequestsPerSecond);

        // 定期补充限速配额
        _ = ReplenishRateLimiterAsync();
    }

    /// <summary>
    /// 异步GET请求（带缓存、重试、限速）
    /// </summary>
    public async Task<T> GetAsync<T>(string url, bool useCache = true,
                                      TimeSpan? cacheTtl = null,
                                      CancellationToken ct = default)
    {
        string cacheKey = $"GET:{url}";

        // 尝试从缓存获取
        if (useCache)
        {
            T cached = _cache.Get<T>(cacheKey);
            if (cached != null)
            {
                _logger.LogDebug($"[Cache HIT] {url}");
                return cached;
            }
        }

        // 限速等待
        await _rateLimiter.WaitAsync(ct);

        // 执行请求（带重试）
        T result = await ExecuteWithRetryAsync(async () =>
        {
            _logger.LogInfo($"[GET] {url}");

            using (var cts = CancellationTokenSource.CreateLinkedTokenSource(ct))
            {
                cts.CancelAfter(DefaultTimeout);

                HttpResponseMessage response = await _httpClient.GetAsync(url, cts.Token);
                response.EnsureSuccessStatusCode();

                string json = await response.Content.ReadAsStringAsync(ct);
                return JsonSerializer.Deserialize<T>(json);
            }
        });

        // 存入缓存
        if (useCache && result != null)
        {
            var cacheOptions = new MemoryCacheEntryOptions
            {
                AbsoluteExpirationRelativeToNow = cacheTtl ?? TimeSpan.FromMinutes(5),
                Size = 1
            };
            _cache.Set(cacheKey, result, cacheOptions);
            _logger.LogDebug($"[Cache SET] {url}, TTL={cacheOptions.AbsoluteExpirationRelativeToNow}");
        }

        return result;
    }

    /// <summary>
    /// 异步POST请求
    /// </summary>
    public async Task<T> PostAsync<T>(string url, object body,
                                       CancellationToken ct = default)
    {
        await _rateLimiter.WaitAsync(ct);

        string jsonBody = JsonSerializer.Serialize(body);
        _logger.LogInfo($"[POST] {url}, Body: {jsonBody.Substring(0, Math.Min(100, jsonBody.Length))}...");

        return await ExecuteWithRetryAsync(async () =>
        {
            using (var content = new StringContent(jsonBody, Encoding.UTF8, "application/json"))
            using (var cts = CancellationTokenSource.CreateLinkedTokenSource(ct))
            {
                cts.CancelAfter(DefaultTimeout);

                HttpResponseMessage response = await _httpClient.PostAsync(url, content, cts.Token);
                response.EnsureSuccessStatusCode();

                string responseJson = await response.Content.ReadAsStringAsync(ct);
                return JsonSerializer.Deserialize<T>(responseJson);
            }
        });
    }

    /// <summary>
    /// 带重试的执行器
    /// </summary>
    private async Task<T> ExecuteWithRetryAsync<T>(Func<Task<T>> operation)
    {
        Exception lastException = null;

        for (int attempt = 1; attempt <= MaxRetries; attempt++)
        {
            try
            {
                if (attempt > 1)
                {
                    _logger.LogWarning($"[Retry] 第{attempt}/{MaxRetries}次尝试...");
                    await Task.Delay(RetryDelay * attempt);  // 指数退避
                }

                return await operation();
            }
            catch (HttpRequestException ex) when (attempt < MaxRetries)
            {
                lastException = ex;
                _logger.LogError($"[Error] HTTP错误: {ex.StatusCode} - {ex.Message}");
            }
            catch (TaskCanceledException ex) when (attempt < MaxRetries && !ex.CancellationToken.IsCancellationRequested)
            {
                lastException = ex;
                _logger.LogError($"[Error] 请求超时");
            }
            catch (Exception ex)
            {
                _logger.LogError($"[Fatal] 不可恢复的错误: {ex.Message}");
                throw;  // 非临时性错误，直接抛出
            }
        }

        throw new HttpRequestException($"请求失败（已重试{MaxRetries}次）", lastException);
    }

    /// <summary>
    /// 定期补充限速配额
    /// </summary>
    private async Task ReplenishRateLimiterAsync()
    {
        while (true)
        {
            await Task.Delay(1000);  // 每秒补充一次

            int currentCount = MaxRequestsPerSecond - _rateLimiter.CurrentCount;
            if (currentCount > 0)
            {
                _rateLimiter.Release(currentCount);
            }
        }
    }

    // 清理资源
    public void Dispose()
    {
        _httpClient?.Dispose();
        _cache?.Dispose();
        _rateLimiter?.Dispose();
    }
}
```

### 练习4：异步批处理器
**题目**：设计一个通用的异步批处理器，能够：
- 接收一批任务
- 控制最大并发数（如最多同时5个任务）
- 支持整体超时
- 提供实时进度回调
- 收集所有任务的执行结果（成功/失败）
- 生成详细的执行报告

<details>
<summary>查看答案</summary>

```csharp
public class AsyncBatchProcessor<TInput, TResult>
{
    private readonly Func<TInput, CancellationToken, Task<TResult>> _processor;
    private readonly int _maxConcurrency;
    private readonly ILogger _logger;

    public AsyncBatchProcessor(
        Func<TInput, CancellationToken, Task<TResult>> processor,
        int maxConcurrency = 5,
        ILogger logger = null)
    {
        _processor = processor;
        _maxConcurrency = maxConcurrency;
        _logger = logger ?? new ConsoleLogger();
    }

    /// <summary>
    /// 批量处理任务
    /// </summary>
    public async Task<BatchProcessResult<TResult>> ProcessAsync(
        IEnumerable<TInput> items,
        TimeSpan? overallTimeout = null,
        IProgress<BatchProgress> progress = null,
        CancellationToken externalCt = default)
    {
        var itemList = items.ToList();
        int totalItems = itemList.Count;

        _logger.LogInfo($"开始批量处理: {totalItems} 个任务, 最大并发: {_maxConcurrency}");

        Stopwatch sw = Stopwatch.StartNew();
        var results = new List<ItemResult<TResult>>(totalItems);
        int completedCount = 0;
        int successCount = 0;
        int failureCount = 0;

        // 使用SemaphoreSlim限制并发数
        using var semaphore = new SemaphoreSlim(_maxConcurrency, _maxConcurrency);
        // 使用CancellationTokenSource支持超时
        using var cts = CancellationTokenSource.CreateLinkedTokenSource(externalCt);

        if (overallTimeout.HasValue)
            cts.CancelAfter(overallTimeout.Value);

        // 创建所有任务
        var tasks = itemList.Select(async (item, index) =>
        {
            await semaphore.WaitAsync(cts.Token);

            try
            {
                _logger.LogDebug($"[任务{index + 1}] 开始处理...");

                TResult result = await _processor(item, cts.Token);

                Interlocked.Increment(ref successCount);
                var itemResult = new ItemResult<TResult>
                {
                    Index = index,
                    Input = item,
                    Success = true,
                    Result = result
                };

                Interlocked.Increment(ref completedCount);
                ReportProgress(progress, completedCount, totalItems, successCount, failureCount);

                _logger.LogDebug($"[任务{index + 1}] ✓ 完成");
                return itemResult;
            }
            catch (OperationCanceledException) when (cts.IsCancellationRequested)
            {
                Interlocked.Increment(ref failureCount);
                var itemResult = new ItemResult<TResult>
                {
                    Index = index,
                    Input = item,
                    Success = false,
                    Error = "已取消"
                };

                Interlocked.Increment(ref completedCount);
                ReportProgress(progress, completedCount, totalItems, successCount, failureCount);

                _logger.LogWarn($"[任务{index + 1}] ✗ 已取消");
                return itemResult;
            }
            catch (Exception ex)
            {
                Interlocked.Increment(ref failureCount);
                var itemResult = new ItemResult<TResult>
                {
                    Index = index,
                    Input = item,
                    Success = false,
                    Error = ex.Message,
                    Exception = ex
                };

                Interlocked.Increment(ref completedCount);
                ReportProgress(progress, completedCount, totalItems, successCount, failureCount);

                _logger.LogError($"[任务{index + 1}] ✗ 失败: {ex.Message}");
                return itemResult;
            }
            finally
            {
                semaphore.Release();
            }
        }).ToArray();

        // 等待所有任务完成
        try
        {
            await Task.WhenAll(tasks);
        }
        catch
        {
            // 单个任务的异常已经在上面的catch中处理了
        }

        sw.Stop();

        // 构建结果
        var batchResult = new BatchProcessResult<TResult>
        {
            TotalItems = totalItems,
            SuccessCount = successCount,
            FailureCount = failureCount,
            Results = tasks.Select(t => t.Result).OrderBy(r => r.Index).ToList(),
            ElapsedMs = sw.ElapsedMilliseconds,
            IsCancelled = cts.IsCancellationRequested
        };

        // 输出报告
        PrintReport(batchResult);

        return batchResult;
    }

    private void ReportProgress(IProgress<BatchProgress> progress,
                                 int completed, int total, int success, int failed)
    {
        progress?.Report(new BatchProgress
        {
            Completed = completed,
            Total = total,
            SuccessCount = success,
            FailureCount = failed,
            Percentage = (double)completed / total * 100
        });
    }

    private void PrintReport(BatchProcessResult<TResult> result)
    {
        Console.WriteLine($"\n{'=',60}");
        Console.WriteLine("  批量处理报告");
        Console.WriteLine($"{'=',60}");
        Console.WriteLine($"总任务数:   {result.TotalItems}");
        Console.WriteLine($"成功:       {result.SuccessCount} ({(double)result.SuccessCount/result.TotalItems:P1})");
        Console.WriteLine($"失败:       {result.FailureCount} ({(double)result.FailureCount/result.TotalItems:P1})");
        Console.WriteLine($"总耗时:     {result.ElapsedMs}ms");
        Console.WriteLine($"是否取消:   {(result.IsCancelled ? "是" : "否")}");

        if (result.FailureCount > 0)
        {
            Console.WriteLine($"\n失败的任务:");
            foreach (var failed in result.Results.Where(r => !r.Success))
            {
                Console.WriteLine($"  #{failed.Index + 1}: {failed.Error}");
            }
        }

        Console.WriteLine($"{'=',60}\n");
    }
}

                throw new Exception($"模拟错误（项目{itemId}）");

            return $"结果-{itemId}";
        }

        // 创建处理器（最多3个并发）
        var processor = new AsyncBatchProcessor<int, string>(
            ProcessItemAsync,
            maxConcurrency: 3
        );

        // 准备数据
        var items = Enumerable.Range(1, 20).ToList();

        // 执行批量处理
        var result = await processor.ProcessAsync(
            items,
            overallTimeout: TimeSpan.FromSeconds(30),
            progress: new Progress<BatchProgress>(p =>
            {
                string bar = new string('█', (int)(p.Percentage / 2.5));
                Console.WriteLine($"\r进度: [{bar,-40}] {p.Percentage:F0}% " +
                               $"({p.Completed}/{p.Total}) " +
                               $"✓{p.SuccessCount} ✗{p.FailureCount}")
            })
        );

        Console.WriteLine($"最终结果: {result.SuccessCount}成功, {result.FailureCount}失败");
    }
}
```

### 练习5：终极挑战 - 异步管道系统
**题目**：构建一个异步数据处理管道系统，支持：
- 多个处理阶段（Stage），按顺序或并行执行
- 每个阶段可以有自己的并发度配置
- 支持条件分支（根据数据选择不同处理路径）
- 错误隔离（单个项目的失败不影响其他项目）
- 实时监控仪表盘（显示各阶段的吞吐量、成功率、队列深度）
- 动态调整（运行时修改并发度）

```csharp
/// <summary>
/// 异步数据处理管道
/// </summary>
public class AsyncPipeline<TInput, TOutput>
{
    private readonly List<PipelineStage> _stages = new();
    private readonly PipelineMetrics _metrics = new();
    private readonly ILogger _logger;
    private int _currentConcurrency = 5;
    private volatile bool _isRunning = false;

    public AsyncPipeline(ILogger logger = null)
    {
        _logger = logger ?? new ConsoleLogger();
    }

    /// <summary>
    /// 添加处理阶段
    /// </summary>
    public AsyncPipeline<TInput, TOutput> AddStage<TStageIn, TStageOut>(
        string name,
        Func<TStageIn, CancellationToken, Task<TStageOut>> processor,
        int? maxConcurrency = null)
    {
        _stages.Add(new PipelineStage
        {
            Name = name,
            Processor = async (input, ct) => await processor((TStageIn)input, ct),
            MaxConcurrency = maxConcurrency ?? _currentConcurrency
        });

        return this;
    }

    /// <summary>
    /// 添加条件分支阶段
    /// </summary>
    public AsyncPipeline<TInput, TOutput> AddConditionalStage<TStageIn>(
        string name,
        Func<TStageIn, bool> condition,
        Func<TStageIn, CancellationToken, Task<TStageOut>> trueBranch,
        Func<TStageIn, CancellationToken, Task<TStageOut>> falseBranch)
    {
        _stages.Add(new PipelineStage
        {
            Name = name,
            IsConditional = true,
            Condition = input => condition((TStageIn)input),
            TrueBranch = async (input, ct) => await trueBranch((TStageIn)input, ct),
            FalseBranch = async (input, ct) => await falseBranch((TStageIn)input, ct),
            MaxConcurrency = _currentConcurrency
        });

        return this;
    }

    /// <summary>
    /// 执行管道
    /// </summary>
    public async Task<PipelineResult<TOutput>> ExecuteAsync(
        IEnumerable<TInput> items,
        CancellationToken ct = default)
    {
        if (_stages.Count == 0)
            throw new InvalidOperationException("管道至少需要一个阶段");

        _isRunning = true;
        _metrics.Reset();
        var stopwatch = Stopwatch.StartNew();

        _logger.LogInfo($"🚀 管道启动 | 输入项: {items.Count()} | 阶段数: {_stages.Count}");

        try
        {
            // 初始输入转换为object类型以便在阶段间传递
            var currentItems = items.Cast<object>().ToList();

            // 依次通过每个阶段
            for (int stageIndex = 0; stageIndex < _stages.Count; stageIndex++)
            {
                if (ct.IsCancellationRequested) break;

                var stage = _stages[stageIndex];
                var stageMetrics = _metrics.GetOrCreateStage(stage.Name);
                stageMetrics.StartTime = stopwatch.ElapsedMilliseconds;

                _logger.LogInfo($"\n▶ 阶段 {stageIndex + 1}/{_stages.Count}: {stage.Name}" +
                               $" | 输入: {currentItems.Count}项 | 并发: {stage.MaxConcurrency}");

                // 处理当前阶段
                currentItems = await ProcessStageAsync(stage, currentItems, stageMetrics, ct);

                stageMetrics.EndTime = stopwatch.ElapsedMilliseconds;
                stageMetrics.OutputCount = currentItems.Count;

                _logger.LogInfo($"  ✓ {stage.Name} 完成 | 输出: {currentItems.Count}项 | " +
                               $"耗时: {stageMetrics.Duration}ms | " +
                               $"成功: {stageMetrics.SuccessCount} | 失败: {stageMetrics.FailureCount}");
            }

            stopwatch.Stop();
            _isRunning = false;

            var finalResults = currentItems.Cast<TOutput>().ToList();

            var pipelineResult = new PipelineResult<TOutput>
            {
                Success = !ct.IsCancellationRequested,
                Results = finalResults,
                TotalInput = items.Count(),
                SuccessfulOutput = finalResults.Count,
                Metrics = _metrics.Snapshot(),
                ElapsedMs = stopwatch.ElapsedMilliseconds
            };

            PrintFinalReport(pipelineResult);
            return pipelineResult;
        }
        catch (Exception ex)
        {
            _isRunning = false;
            _logger.LogError($"管道执行异常: {ex.Message}");
            throw;
        }
    }

    private async Task<List<object>> ProcessStageAsync(
        PipelineStage stage,
        List<object> inputs,
        StageMetrics metrics,
        CancellationToken ct)
    {
        var outputs = new List<object>();
        var semaphore = new SemaphoreSlim(stage.MaxConcurrency, stage.MaxConcurrency);

        var tasks = inputs.Select(async (input, index) =>
        {
            await semaphore.WaitAsync(ct);
            Interlocked.Increment(ref metrics.QueuedCount);

            try
            {
                object result;

                if (stage.IsConditional)
                {
                    // 条件分支
                    bool cond = stage.Condition(input);
                    result = cond ?
                        await stage.TrueBranch(input, ct) :
                        await stage.FalseBranch(input, ct);
                }
                else
                {
                    // 普通处理
                    result = await stage.Processor(input, ct);
                }

                Interlocked.Increment(ref metrics.SuccessCount);
                lock (outputs) outputs.Add(result);

                return true;
            }
            catch (Exception ex)
            {
                Interlocked.Increment(ref metrics.FailureCount);
                _logger.LogError($"  [{stage.Name}] 项目{index} 失败: {ex.Message}");
                return false;
            }
            finally
            {
                semaphore.Release();
            }
        }).ToArray();

        await Task.WhenAll(tasks);
        return outputs;
    }

    /// <summary>
    /// 动态调整并发度
    /// </summary>
    public void SetConcurrency(int concurrency)
    {
        _currentConcurrency = Math.Max(1, concurrency);
        _logger.LogInfo($"并发度调整为: {_currentConcurrency}");
    }

    /// <summary>
    /// 获取实时监控数据
    /// </summary>
    public PipelineSnapshot GetLiveMetrics() => _metrics.Snapshot();

    private void PrintFinalReport(PipelineResult<TOutput> result)
    {
        Console.WriteLine($"\n{'═',65}");
        Console.WriteLine("  📊 管道执行报告");
        Console.WriteLine($"{'═',65}");
        Console.WriteLine($"状态:       {(result.Success ? "✅ 成功" : "⚠️ 中断")}");
        Console.WriteLine($"输入项数:   {result.TotalInput}");
        Console.WriteLine($"输出项数:   {result.SuccessfulOutput}");
        Console.WriteLine($"总耗时:     {result.ElapsedMs}ms");
        Console.WriteLine($"吞吐量:     {result.Throughput:F1} 项/秒");

        Console.WriteLine($"\n各阶段详情:");

        foreach (var stage in result.Metrics.StageMetrics)
        {
            string status = stage.FailureCount == 0 ? "✓" :
                           stage.FailureCount < stage.InputCount ? "⚠️" : "✗";

            Console.WriteLine($"  {status} {stage.Name,-18} " +
                           $"输入:{stage.InputCount,4} " +
                           $"输出:{stage.OutputCount,4} " +
                           $"成功:{stage.SuccessCount,4} " +
                           $"失败:{stage.FailureCount,4} " +
                           $"耗时:{stage.Duration,5}ms");
        }

        Console.WriteLine($"{'═',65}\n");
    }

    // 内部类型
    private class PipelineStage
    {
        public string Name { get; set; }
        public Func<object, CancellationToken, Task<object>> Processor { get; set; }
        public bool IsConditional { get; set; }
        public Func<object, bool> Condition { get; set; }
        public Func<object, CancellationToken, Task<object>> TrueBranch { get; set; }
        public Func<object, CancellationToken, Task<object>> FalseBranch { get; set; }
        public int MaxConcurrency { get; set; }
    }

    private class StageMetrics
    {
        public string Name { get; set; }
        public int InputCount { get; set; }
        public int OutputCount { get; set; }
        public int SuccessCount { get; set; }
        public int FailureCount { get; set; }
        public int QueuedCount { get; set; }
        public long StartTime { get; set; }
        public long EndTime { get; set; }
        public long Duration => EndTime - StartTime;
    }

    private class PipelineMetrics
    {
        private readonly List<StageMetrics> _stages = new();
        private readonly object _lock = new();

        public void Reset()
        {
            lock (_lock) _stages.Clear();
        }

        public StageMetrics GetOrCreateStage(string name)
        {
            lock (_lock)
            {
                var existing = _stages.FirstOrDefault(s => s.Name == name);
                if (existing == null)
                {
                    existing = new StageMetrics { Name = name };
                    _stages.Add(existing);
                }
                return existing;
            }
        }

        public PipelineSnapshot Snapshot()
        {
            lock (_lock)
            {
                return new PipelineSnapshot
                {
                    StageMetrics = _stages.ToList(),
                    Timestamp = DateTime.Now
                };
            }
        }
    }
}

{
    public bool Success { get; set; }
    public List<TOutput> Results { get; set; }
    public int TotalInput { get; set; }
    public int SuccessfulOutput { get; set; }
    public PipelineSnapshot Metrics { get; set; }
    public long ElapsedMs { get; set; }
    public double Throughput => ElapsedMs > 0 ? (double)SuccessfulOutput / ElapsedMs * 1000 : 0;
}

public class PipelineSnapshot
```

## 八、总结

异步编程是现代高性能应用的基石，特别是在Web开发领域：

### 核心理解

1. **async/await只是语法糖**：底层是基于状态机的编译器转换
2. **异步 != 多线程**：异步是关于不阻塞，多线程是关于并行计算
3. **异步让服务器更高效**：少量线程即可处理大量并发请求
4. **async会传染**：一旦用了async，最好一路async到底

### 学习建议

1. **从简单开始**：先用`async/await`替代所有的`Task.Result`和`.Wait()`
2. **理解原理**：了解状态机、SynchronizationContext等概念
3. **实践出真知**：在实际项目中大量使用，遇到问题再深入研究
4. **阅读源码**：看看.NET Core中异步的实现方式

### 下一步学习方向

```
异步编程基础（本章）
    ↓
深入理解Task内部机制
    ↓
异步流（IAsyncEnumerable<T>）
    ↓
Channels（生产者-消费者模式）
    ↓
性能优化和Benchmark测试
    ↓
分布式系统的异步通信
```

> **记住**：在现代Web开发中，**几乎所有的I/O操作都应该是异步的**。这不是可选项，而是必选项。掌握了异步编程，你就迈出了成为专业.NET开发者的重要一步！
