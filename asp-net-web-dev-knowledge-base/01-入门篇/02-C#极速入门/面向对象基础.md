## 一、为什么需要面向对象？

### 1.1 现实世界的类比

想象你在开发一个电商系统：

**没有OOP（面向对象）时的问题：**
```csharp
// 用户1的数据 - 散落各处
string user1Name = "张三";
int user1Age = 25;
string user1Email = "zhangsan@email.com";
decimal user1Balance = 1000.00m;

// 用户2的数据 - 又要重复定义
string user2Name = "李四";
int user2Age = 30;
string user2Email = "lisi@email.com";
decimal user2Balance = 2500.00m;

// 1000个用户呢？10000个？代码会乱成一团！
```

**使用OOP后的改进：**
```csharp
// 定义一个"模板"（类）
public class User
{
    public string Name { get; set; }
    public int Age { get; set; }
    public string Email { get; set; }
    public decimal Balance { get; set; }

    // 行为也封装在一起
    public void Recharge(decimal amount)
    {
        Balance += amount;
        Console.WriteLine($"{Name} 充值 ¥{amount}，余额: ¥{Balance}");
    }
}

// 像做饼干一样，用模板创建无数个"对象"
var user1 = new User { Name = "张三", Age = 25, Balance = 1000 };
var user2 = new User { Name = "李四", Age = 30, Balance = 2500 };

user1.Recharge(500);  // 每个对象都能执行自己的行为
```

### 1.2 OOP的三大核心优势

| 优势 | 说明 | 生活类比 |
|------|------|----------|
| **封装** | 数据和行为打包在一起 | 手机把屏幕、电池、芯片都装在一个壳子里 |
| **继承** | 复用现有代码，扩展功能 | 你继承了父母的基因，又有自己的特点 |
| **多态** | 同一个接口，不同实现 | USB接口可以插U盘、鼠标、键盘等不同设备 |

## 二、类与对象

### 2.1 什么是类？（蓝图/模板）

类就像是一个**设计图纸**或**饼干模具**，它定义了：
- **属性**：对象有什么特征（数据）
- **方法**：对象能做什么（行为）

#### 示例1：设计一个"商品"类

```csharp
/// <summary>
/// 商品类 - 这是设计图纸，不是实际的商品
/// </summary>
public class Product
{
    // ===== 属性：商品的特征 =====

    /// <summary>
    /// 商品ID
    /// </summary>
    public int Id { get; set; }

    /// <summary>
    /// 商品名称
    /// </summary>
    public string Name { get; set; }

    /// <summary>
    /// 商品价格
    /// </summary>
    public decimal Price { get; set; }

    /// <summary>
    /// 库存数量
    /// </summary>
    public int Stock { get; set; }

    /// <summary>
    /// 商品分类
    /// </summary>
    public string Category { get; set; }

    /// <summary>
    /// 上架时间
    /// </summary>
    public DateTime CreatedAt { get; set; }


    // ===== 方法：商品的行为 =====

    /// <summary>
    /// 显示商品信息
    /// </summary>
    public void DisplayInfo()
    {
        Console.WriteLine($"=== 商品信息 ===");
        Console.WriteLine($"ID: {Id}");
        Console.WriteLine($"名称: {Name}");
        Console.WriteLine($"价格: ¥{Price:F2}");
        Console.WriteLine($"库存: {Stock}件");
        Console.WriteLine($"分类: {Category}");
        Console.WriteLine($"上架时间: {CreatedAt:yyyy-MM-dd}");
    }

    /// <summary>
    /// 判断是否有库存
    /// </summary>
    public bool IsInStock()
    {
        return Stock > 0;
    }

    /// <summary>
    /// 应用折扣并返回折后价格
    /// </summary>
    public decimal GetDiscountedPrice(decimal discountRate)
    {
        if (discountRate < 0 || discountRate > 1)
        {
            throw new ArgumentException("折扣率必须在0-1之间");
        }

        decimal discountedPrice = Price * (1 - discountRate);
        Console.WriteLine($"{Name} 原价 ¥{Price:F2}，折扣 {(discountRate * 100):F0}%，现价 ¥{discountedPrice:F2}");

        return discountedPrice;
    }

    /// <summary>
    /// 减少库存（带验证）
    /// </summary>
    public bool ReduceStock(int quantity)
    {
        if (quantity <= 0)
        {
            Console.WriteLine("错误: 数量必须大于0");
            return false;
        }

        if (quantity > Stock)
        {
            Console.WriteLine($"错误: 库存不足。需要 {quantity}件，当前仅 {Stock}件");
            return false;
        }

        Stock -= quantity;
        Console.WriteLine($"{Name} 出库 {quantity}件，剩余库存: {Stock}件");
        return true;
    }
}
```

### 2.2 什么是对象？（实例）

对象是根据类创建的**具体实例**，就像根据图纸盖好的房子。

#### 示例2：创建和使用商品对象

```csharp
public class ProductDemo
{
    public static void RunDemo()
    {
        Console.WriteLine("=== 创建商品对象示例 ===\n");

        // 方式一：使用对象初始化器（推荐）
        var iPhone = new Product
        {
            Id = 1,
            Name = "iPhone 15 Pro",
            Price = 8999.00m,
            Stock = 100,
            Category = "手机",
            CreatedAt = DateTime.Now.AddDays(-10)
        };

        // 方式二：先创建再赋值
        var macBook = new Product();
        macBook.Id = 2;
        macBook.Name = "MacBook Pro 14寸";
        macBook.Price = 14999.00m;
        macBook.Stock = 50;
        macBook.Category = "电脑";
        macBook.CreatedAt = DateTime.Now;

        // 使用对象的属性和方法
        Console.WriteLine("--- iPhone 信息 ---");
        iPhone.DisplayInfo();
        Console.WriteLine($"有库存吗? {iPhone.IsInStock()}");
        Console.WriteLine();

        Console.WriteLine("--- MacBook 信息 ---");
        macBook.DisplayInfo();

        // 使用方法
        Console.WriteLine("\n--- 操作演示 ---");
        Console.WriteLine($"\niPhone 打8折:");
        iPhone.GetDiscountedPrice(0.20m);

        Console.WriteLine($"\nMacBook 减少库存:");
        bool success = macBook.ReduceStock(5);
        if (success)
        {
            Console.WriteLine("出库成功！");
        }

        // 错误情况测试
        Console.WriteLine($"\niPhone 尝试减少过多库存:");
        iPhone.ReduceStock(200);  // 会失败
    }
}

// 运行演示
ProductDemo.RunDemo();
```

### 2.3 类 vs 对象对比表

| 特征 | 类 (Class) | 对象 (Object) |
|------|-----------|---------------|
| 本质 | 设计图纸/模板 | 根据图纸建造的房子 |
| 数量 | 只有一个定义 | 可以创建无数个实例 |
| 占用内存 | 不占用（只是定义） | 占用实际内存存储数据 |
| 存在位置 | 代码文件中 | 运行时的内存中 |
| 类比 | 饼干模具 | 模具压出来的饼干 |

## 三、属性详解

属性是类的"特征"，用于存储和访问数据。

### 3.1 自动属性（最常用）

```csharp
public class Customer
{
    // 自动属性：编译器自动生成私有字段
    public int Id { get; set; }
    public string Name { get; set; }          // 可读可写
    public DateTime RegisterDate { get; }      // 只读（只能在构造函数中设置）
    public string _internalNote { private get; set; }  // 外部只能读，内部可写


    public Customer()
    {
        RegisterDate = DateTime.Now;  // 只读属性的初始化
    }
}
```

### 3.2 完整属性（带逻辑验证）

```csharp
public class BankAccount
{
    // 私有字段（外部无法直接访问）
    private decimal _balance;

    // 完整属性：可以添加验证逻辑
    public decimal Balance
    {
        get
        {
            // 获取值时执行的逻辑
            return _balance;
        }
        set
        {
            // 设置值时执行的逻辑（value是用户传入的新值）
            if (value < 0)
            {
                throw new ArgumentException("余额不能为负数");
            }
            _balance = value;
        }
    }

    // 计算属性：只有get，没有对应的字段
    public string AccountLevel
    {
        get
        {
            if (_balance >= 100000) return "钻石客户";
            if (_balance >= 50000) return "黄金客户";
            if (_balance >= 10000) return "白银客户";
            return "普通客户";
        }
    }

    // 带条件的只读属性
    public bool IsVip => _balance >= 10000;


    public BankAccount(decimal initialBalance)
    {
        Balance = initialBalance;  // 通过属性设置，会触发验证
    }

    public void Deposit(decimal amount)
    {
        if (amount <= 0)
            throw new ArgumentException("存款金额必须大于0");

        _balance += amount;
        Console.WriteLine($"存款 ¥{amount:F2} 成功，当前余额: ¥{_balance:F2}");
    }

    public bool Withdraw(decimal amount)
    {
        if (amount <= 0)
        {
            Console.WriteLine("取款金额必须大于0");
            return false;
        }

        if (amount > _balance)
        {
            Console.WriteLine($"余额不足！当前: ¥{_balance:F2}, 需要: ¥{amount:F2}");
            return false;
        }

        _balance -= amount;
        Console.WriteLine($"取款 ¥{amount:F2} 成功，当前余额: ¥{_balance:F2}");
        return true;
    }

    public void DisplayAccountInfo()
    {
        Console.WriteLine("\n=== 账户信息 ===");
        Console.WriteLine($"账户等级: {AccountLevel}");
        Console.WriteLine($"是否VIP: {(IsVip ? "是" : "否")}");
        Console.WriteLine($"当前余额: ¥{_balance:N2}");
    }
}

// 测试银行账户
var account = new BankAccount(50000.00m);
account.DisplayAccountInfo();  // 黄金客户

account.Deposit(60000.00m);   // 变成110000
account.DisplayAccountInfo();  // 钻石客户

account.Withdraw(2000.00m);    // 正常取款
account.Withdraw(200000.00m);  // 余额不足
```

### 3.3 属性的最佳实践示例

```csharp
public class Employee
{
    public int EmployeeId { get; set; }
    public string FirstName { get; set; }
    public string LastName { get; set; }

    // 组合属性：由其他属性计算得出
    public string FullName => $"{FirstName} {LastName}";

    // 带格式化的计算属性
    public string DisplayName => $"[{EmployeeId:D4}] {FullName}";

    // 私有set：允许内部修改，外部只读
    public decimal BaseSalary { get; private set; }

    // 计算属性：包含复杂逻辑
    public decimal MonthlySalary
    {
        get
        {
            decimal salary = BaseSalary;

            // 工龄奖金
            int yearsOfService = (DateTime.Now - HireDate).Days / 365;
            salary += BaseSalary * (yearsOfService * 0.02m);

            // 绩效奖金
            salary += BaseSalary * PerformanceBonus;

            return Math.Round(salary, 2);
        }
    }

    public decimal PerformanceBonus { get; set; }
    public DateTime HireDate { get; set; }
    public string Department { get; set; }

    public Employee(int id, string firstName, string lastName, decimal baseSalary)
    {
        EmployeeId = id;
        FirstName = firstName;
        LastName = lastName;
        BaseSalary = baseSalary;
        HireDate = DateTime.Now;
        PerformanceBonus = 0;
    }

    // 内部方法可以修改私有set的属性
    public void GiveRaise(decimal percentage)
    {
        if (percentage <= 0 || percentage > 0.5m)  // 最多涨薪50%
        {
            throw new ArgumentException("涨幅必须在0-50%之间");
        }

        BaseSalary *= (1 + percentage);
        Console.WriteLine($"{DisplayName} 涨薪 {(percentage * 100):F0}%，新底薪: ¥{BaseSalary:N2}");
    }

    public void DisplayPaySlip()
    {
        Console.WriteLine("\n==============================");
        Console.WriteLine("         工资条");
        Console.WriteLine("==============================");
        Console.WriteLine($"员工: {DisplayName}");
        Console.WriteLine($"部门: {Department ?? "未分配"}");
        Console.WriteLine($"-----------------------------");
        Console.WriteLine($"底薪: ¥{BaseSalary:N2}");
        Console.WriteLine($"绩效系数: +{(PerformanceBonus * 100):F0}%");
        Console.WriteLine("-----------------------------");
        Console.WriteLine($"实发工资: ¥{MonthlySalary:N2}");
        Console.WriteLine("==============================");
    }
}

// 测试员工系统
var emp = new Employee(1001, "张", "三", 15000.00m);
emp.Department = "技术部";
emp.PerformanceBonus = 0.15m;  // 15%绩效奖金
emp.HireDate = DateTime.Now.AddYears(-3);

Console.WriteLine($"员工全名: {emp.FullName}");
Console.WriteLine($"显示名称: {emp.DisplayName}");

emp.DisplayPaySlip();

emp.GiveRaise(0.10m);  // 涨薪10%
emp.DisplayPaySlip();
```

## 四、方法详解

方法是类的"行为"，定义了对象能做什么操作。

### 4.1 方法的组成部分

```csharp
访问修饰符 返回类型 方法名(参数列表)
{
    // 方法体
    return 返回值;  // 如果返回类型不是void
}
```

### 4.2 各种类型的方法示例

```csharp
public class Calculator
{
    // 1. 无参数无返回值
    public void Greet()
    {
        Console.WriteLine("欢迎使用计算器！");
    }

    // 2. 有参数无返回值
    public void PrintSum(int a, int b)
    {
        Console.WriteLine($"{a} + {b} = {a + b}");
    }

    // 3. 无参数有返回值
    public double GetPi()
    {
        return 3.14159265358979;
    }

    // 4. 有参数有返回值
    public int Add(int a, int b)
    {
        return a + b;
    }

    // 5. 多个返回值（使用元组）
    public (int Quotient, int Remainder) DivideWithRemainder(int dividend, int divisor)
    {
        if (divisor == 0)
            throw new ArgumentException("除数不能为零");

        return (dividend / divisor, dividend % divisor);
    }

    // 6. 参数默认值
    public decimal CalculateTax(decimal amount, decimal rate = 0.13m)
    {
        return amount * rate;
    }

    // 7. 可选参数和命名参数
    public string FormatUserInfo(string name, int age, string city = "未知", string country = "中国")
    {
        return $"{name}, {age}岁, 来自{country}{city}";
    }

    // 8. 方法重载（同名但参数不同）
    public int Max(int a, int b) => a > b ? a : b;
    public double Max(double a, double b) => a > b ? a : b;
    public int Max(int a, int b, int c) => Max(Max(a, b), c);


    public void DemonstrateMethods()
    {
        Greet();  // 调用无参方法

        PrintSum(5, 3);  // 输出: 5 + 3 = 8

        double pi = GetPi();
        Console.WriteLine($"π ≈ {pi:F6}");  // π ≈ 3.141593

        int sum = Add(100, 200);
        Console.WriteLine($"100 + 200 = {sum}");

        var result = DivideWithRemainder(17, 5);
        Console.WriteLine($"17 ÷ 5 = {result.Quotient} 余 {result.Remainder}");

        decimal tax = CalculateTax(1000);  // 使用默认税率13%
        Console.WriteLine($"税额: ¥{tax:F2}");

        decimal customTax = CalculateTax(1000, 0.06m);  // 自定义税率6%
        Console.WriteLine($"优惠税率: ¥{customTax:F2}");

        // 命名参数调用（提高可读性）
        string info = FormatUserInfo(
            name: "张三",
            age: 25,
            city: "上海"
        );
        Console.WriteLine(info);

        // 方法重载
        Console.WriteLine($"Max(3, 7) = {Max(3, 7)}");           // 7
        Console.WriteLine($"Max(3.14, 2.71) = {Max(3.14, 2.71)}");  // 3.14
        Console.WriteLine($"Max(5, 9, 3) = {Max(5, 9, 3)}");     // 9
    }
}

// 测试
var calc = new Calculator();
calc.DemonstrateMethods();
```

## 五、构造函数

构造函数在创建对象时自动调用，用于初始化对象的状态。

### 5.1 构造函数的基本用法

```csharp
public class Order
{
    public int OrderId { get; set; }
    public string CustomerName { get; set; }
    public decimal TotalAmount { get; set; }
    public DateTime OrderTime { get; set; }
    public string Status { get; set; }

    // 无参构造函数
    public Order()
    {
        OrderTime = DateTime.Now;
        Status = "待付款";
        Console.WriteLine("✓ 创建了一个新订单（使用默认构造）");
    }

    // 带参构造函数
    public Order(int orderId, string customerName, decimal totalAmount)
    {
        OrderId = orderId;
        CustomerName = customerName;
        TotalAmount = totalAmount;
        OrderTime = DateTime.Now;
        Status = "待付款";

        Console.WriteLine($"✓ 创建订单 #{orderId}，客户: {customerName}，金额: ¥{totalAmount:F2}");
    }

    // 重载构造函数：更多参数
    public Order(int orderId, string customerName, decimal totalAmount, string status)
        : this(orderId, customerName, totalAmount)  // 调用其他构造函数（构造函数链）
    {
        Status = status;  // 只覆盖status，其他复用上面的构造函数
    }

    public void DisplayOrder()
    {
        Console.WriteLine("\n--- 订单详情 ---");
        Console.WriteLine($"订单号: {OrderId}");
        Console.WriteLine($"客户: {CustomerName}");
        Console.WriteLine($"金额: ¥{TotalAmount:F2}");
        Console.WriteLine($"状态: {Status}");
        Console.WriteLine($"时间: {OrderTime:yyyy-MM-dd HH:mm:ss}");
    }
}

// 测试构造函数
Console.WriteLine("=== 测试构造函数 ===\n");

var order1 = new Order();  // 无参构造
order1.OrderId = 1001;
order1.CustomerName = "张三";
order1.TotalAmount = 299.99m;
order1.DisplayOrder();

Console.WriteLine();

var order2 = new Order(1002, "李四", 1599.00m);  // 带参构造
order2.DisplayOrder();

Console.WriteLine();

var order3 = new Order(1003, "王五", 888.00m, "已完成");  // 重载构造
order3.DisplayOrder();
```

### 5.2 构造函数实战：用户注册系统

```csharp
public class User
{
    public int UserId { get; private set; }
    public string Username { get; private set; }
    public string Email { get; private set; }
    public string Phone { get; private set; }
    public DateTime RegisterTime { get; private set; }
    public UserStatus Status { get; private set; }
    public decimal AccountBalance { get; private set; }

    // 枚举：用户状态
    public enum UserStatus
    {
        Active,      // 活跃
        Inactive,    // 不活跃
        Suspended,   // 已暂停
        Banned       // 已封禁
    }

    // 主构造函数：完整注册
    public User(int userId, string username, string email, string phone)
    {
        // 参数验证
        ValidateUsername(username);
        ValidateEmail(email);
        ValidatePhone(phone);

        // 赋值
        UserId = userId;
        Username = username.Trim();
        Email = email.ToLower().Trim();
        Phone = phone.Trim();
        RegisterTime = DateTime.Now;
        Status = UserStatus.Active;
        AccountBalance = 0;

        Console.WriteLine($"✓ 用户 '{username}' 注册成功！");
        Console.WriteLine($"  ID: {UserId}");
        Console.WriteLine($"  时间: {RegisterTime:yyyy-MM-dd HH:mm:ss}");
    }

    // 简化构造函数：只需要用户名和邮箱
    public User(int userId, string username, string email)
        : this(userId, username, email, "")  // 调用主构造函数，phone传空字符串
    {
        Console.WriteLine("  （手机号未填写）");
    }

    // 从数据库恢复用户的构造函数（反序列化场景）
    public User(int userId, string username, string email, string phone,
                DateTime registerTime, UserStatus status, decimal balance)
    {
        UserId = userId;
        Username = username;
        Email = email;
        Phone = phone;
        RegisterTime = registerTime;
        Status = status;
        AccountBalance = balance;
    }

    // 验证方法
    private void ValidateUsername(string username)
    {
        if (string.IsNullOrWhiteSpace(username))
            throw new ArgumentException("用户名不能为空");

        if (username.Length < 3 || username.Length > 20)
            throw new ArgumentException("用户名长度必须在3-20个字符之间");

        if (!Regex.IsMatch(username, @"^[a-zA-Z0-9_\u4e00-\u9fa5]+$"))
            throw new ArgumentException("用户名只能包含字母、数字、下划线和中文");
    }

    private void ValidateEmail(string email)
    {
        if (string.IsNullOrWhiteSpace(email))
            throw new ArgumentException("邮箱不能为空");

        if (!email.Contains("@") || !email.Contains("."))
            throw new ArgumentException("邮箱格式不正确");
    }

    private void ValidatePhone(string phone)
    {
        if (!string.IsNullOrEmpty(phone) && phone.Length != 11)
            throw new ArgumentException("手机号必须是11位数字");
    }

    // 业务方法
    public void Recharge(decimal amount)
    {
        if (amount <= 0)
            throw new ArgumentException("充值金额必须大于0");

        if (Status != UserStatus.Active)
            throw new InvalidOperationException("只有活跃用户才能充值");

        AccountBalance += amount;
        Console.WriteLine($"\n[充值] {Username} 充值 ¥{amount:F2}，余额: ¥{AccountBalance:F2}");
    }

    public bool Consume(decimal amount)
    {
        if (amount <= 0)
        {
            Console.WriteLine("[消费] 金额无效");
            return false;
        }

        if (amount > AccountBalance)
        {
            Console.WriteLine($"[消费] 余额不足！需要 ¥{amount:F2}，当前 ¥{AccountBalance:F2}");
            return false;
        }

        AccountBalance -= amount;
```

## 六、访问修饰符

访问修饰符控制类成员的可访问范围，是实现**封装**的关键。

### 6.1 五种访问修饰符

```csharp
public class AccessModifierDemo
{
    // public：完全公开，任何地方都可以访问
    public string PublicField = "公开字段";

    // private：只在当前类内部可以访问（默认级别）
    private string PrivateField = "私有字段";

    // protected：当前类和子类可以访问
    protected string ProtectedField = "受保护字段";

    // internal：同一个程序集（项目）内可以访问
    internal string InternalField = "内部字段";

    // protected internal：同一程序集或子类可以访问
    protected internal string ProtectedInternalField = "受保护内部字段";


    // 属性也可以有不同的访问修饰符
    public string Name { get; private set; }  // 外部可读，内部可读写
    public decimal Salary { private get; set; }  // 外部可写（通过构造），内部可读

    public AccessModifierDemo()
    {
        // 在类内部，所有成员都可以访问
        Console.WriteLine(PrivateField);           // ✓ 可以
        Console.WriteLine(ProtectedField);         // ✓ 可以
        ModifyPrivateData();                       // ✓ 可以调用私有方法
    }

    // 私有方法：辅助方法，不对外暴露
    private void ModifyPrivateData()
    {
        PrivateField = "已修改";
    }

    // 公共方法：对外提供的服务
    public void PublicMethod()
    {
        Console.WriteLine("这是公共方法");
        InternalLogic();  // 内部调用私有方法
    }

    // 受保护方法：供子类重写
    protected virtual void InternalLogic()
    {
        Console.WriteLine("内部逻辑（子类可重写）");
    }
}
```

### 6.2 封装的实战意义

```csharp
/// <summary>
/// ATM卡类 - 展示如何正确使用访问修饰符实现封装
/// </summary>
public class ATMCard
{
    // ===== 完全私有的字段（外部绝对不能直接访问）=====
    private string _cardNumber;
    private string _pinCode;           // PIN码必须保密
    private decimal _balance;
    private int _failedPinAttempts;
    private const int MaxPinAttempts = 3;
    private bool _isLocked;


    // ===== 公开的只读属性（外部只能查看，不能修改）=====
    public string MaskedCardNumber => _cardNumber?.Substring(0, 4) + "****" + _cardNumber?.Substring(12);
    public bool IsLocked => _isLocked;
    public decimal Balance => _balance;  // 只允许查看余额


    // ===== 构造函数 =====
    public ATMCard(string cardNumber, string pinCode, decimal initialBalance)
    {
        _cardNumber = cardNumber;
        _pinCode = pinCode;
        _balance = initialBalance;
        _failedPinAttempts = 0;
        _isLocked = false;
    }


    // ===== 公共方法（对外提供的安全操作接口）=====

    /// <summary>
    /// 验证PIN码
    /// </summary>
    public bool VerifyPin(string inputPin)
    {
        if (_isLocked)
        {
            Console.WriteLine("卡片已被锁定");
            return false;
        }

        if (inputPin == _pinCode)
        {
            Console.WriteLine("PIN码验证成功");
            _failedPinAttempts = 0;  // 重置计数器
            return true;
        }
        else
        {
            _failedPinAttempts++;
            Console.WriteLine($"PIN码错误！（剩余尝试次数: {MaxPinAttempts - _failedPinAttempts})");

            if (_failedPinAttempts >= MaxPinAttempts)
            {
                LockCard();
            }

            return false;
        }
    }

    /// <summary>
    /// 取款（公共接口，带有完整的验证逻辑）
    /// </summary>
    public WithdrawResult Withdraw(decimal amount)
    {
        // 内部调用私有验证方法
        var validation = ValidateWithdrawal(amount);
        if (!validation.IsValid)
        {
            return new WithdrawResult { Success = false, Message = validation.ErrorMessage };
        }

        // 执行取款（通过私有方法）
        ExecuteWithdrawal(amount);

        return new WithdrawResult
        {
            Success = true,
            Message = $"取款成功 ¥{amount:F2}",
            NewBalance = _balance
        };
    }

    /// <summary>
    /// 存款
    /// </summary>
    public DepositResult Deposit(decimal amount)
    {
        if (amount <= 0)
            return new DepositResult { Success = false, Message = "存款金额必须大于0" };

        if (amount > 50000)
            return new DepositResult { Success = false, Message = "单笔存款不能超过¥50,000" };

        _balance += amount;

        return new DepositResult
        {
            Success = true,
            Message = $"存款成功 ¥{amount:F2}",
            NewBalance = _balance
        };
    }


    // ===== 私有方法（内部实现细节，外部不可见）=====

    private ValidationResult ValidateWithdrawal(decimal amount)
    {
        if (_isLocked)
            return new ValidationResult { IsValid = false, ErrorMessage = "卡片已锁定" };

        if (amount <= 0)
            return new ValidationResult { IsValid = false, ErrorMessage = "金额必须大于0" };

        if (amount > _balance)
            return new ValidationResult { IsValid = false, ErrorMessage = $"余额不足（当前: ¥{_balance:F2}）" };

        if (amount > 5000)
            return new ValidationResult { IsValid = false, ErrorMessage = "单笔取款不能超过¥5,000" };

        return new ValidationResult { IsValid = true };
    }

    private void ExecuteWithdrawal(decimal amount)
    {
        _balance -= amount;
    }

    private void LockCard()
    {
        _isLocked = true;
        Console.WriteLine("\n⚠️  卡片已被锁定！请联系银行解锁。");
    }


    // ===== 结果类（用于返回操作结果）=====
    public class WithdrawResult
    {
        public bool Success { get; set; }
        public string Message { get; set; }
        public decimal NewBalance { get; set; }
    }

    public class DepositResult
    {
        public bool Success { get; set; }
        public string Message { get; set; }
        public decimal NewBalance { get; set; }
    }

    private class ValidationResult
    {
        public bool IsValid { get; set; }
        public string ErrorMessage { get; set; }
    }
}
```

## 七、this关键字

`this`关键字引用当前对象的实例，用于区分成员变量和参数、调用其他构造函数等。

### 7.1 this的基本用法

```csharp
public class Student
{
    // 字段
    private string _name;
    private int _age;
    private List<int> _scores;

    // this用于区分字段和参数
    public Student(string name, int age)
    {
        this._name = name;      // this._name 是字段，name 是参数
        this._age = age;        // this.age 是字段，age 是参数
        this._scores = new List<int>();
    }

    // this用于调用当前对象的其它方法
    public void AddScore(int score)
    {
        if (IsValidScore(score))  // 相当于 this.IsValidScore(score)
        {
            _scores.Add(score);
            Console.WriteLine($"{_name} 的成绩已添加: {score}");
        }
    }

    // this作为返回值，支持链式调用
    public Student SetName(string name)
    {
        this._name = name;
        return this;  // 返回当前对象
    }

    public Student SetAge(int age)
    {
        this._age = age;
        return this;
    }

    public void DisplayInfo()
    {
        Console.WriteLine($"\n学生: {_name}, 年龄: {_age}");
        if (_scores.Any())
        {
            Console.WriteLine($"成绩: [{string.Join(", ", _scores)}]");
            Console.WriteLine($"平均分: {_scores.Average():F1}");
        }
    }

    private bool IsValidScore(int score)
    {
        return score >= 0 && score <= 100;
    }
}
```

```csharp
    }

    // this用于索引器（高级用法）
    public CartItem this[int index]
    {
        get
        {

                return _items[index];
            throw new IndexOutOfRangeException();
        }
    }

    // 计算总价
    public decimal CalculateTotal()
    {
        decimal subtotal = _items.Sum(item => item.TotalPrice);

        Console.WriteLine($"\n{'=',40}");

        Console.WriteLine($"{'-',40}");

        foreach (var item in _items)
        {

        }

        Console.WriteLine($"{'-',40}");
        Console.WriteLine($"{"小计:",28} ¥{subtotal,10:F2}");

        if (_discountRate > 0)
        {
            Console.WriteLine($"{"折扣 (-" + (_discountRate * 100) + "%):",28} -¥{discount,9:F2}");

        Console.WriteLine($"{"总计:",28} ¥{total,10:F2}");
```

## 九、最佳实践总结

### 9.1 类设计原则

| 原则 | 说明 | 示例 |
|------|------|------|
| 单一职责 | 一个类只做一件事 | `User`类管理用户，`Order`类管理订单 |
| 封装 | 隐藏内部细节，暴露必要接口 | 字段用private，通过public方法访问 |
| 低耦合 | 类之间依赖尽可能少 | 通过接口交互，而非直接访问内部 |
| 高内聚 | 相关的功能放在一起 | 用户的所有相关方法都在User类中 |

### 9.2 命名规范速查

| 类型 | 规范 | 示例 |
|------|------|------|
| 类名 | PascalCase，名词 | `Customer`, `ShoppingCart` |
| 方法名 | PascalCase，动词开头 | `GetUser()`, `CalculateTotal()` |
| 属性名 | PascalCase，名词 | `UserName`, `IsVerified` |
| 公共字段 | PascalCase（避免使用） | `MaxSize` |
| 私有字段 | _camelCase | `_connectionString`, `_userId` |
| 常量 | PascalCase | `DefaultTimeout`, `MaxRetryCount` |
| 参数/局部变量 | camelCase | `userName`, `orderList` |

### 9.3 代码质量检查清单

- [ ] 类名是否清晰表达了这个类的职责？
- [ ] 是否遵循了单一职责原则（不要让类太庞大）？
- [ ] 字段是否都是private，通过属性暴露？
- [ ] 属性是否添加了必要的验证逻辑？
- [ ] 构造函数是否正确初始化了所有必需的字段？
- [ ] 方法是否职责单一，长度适中（不超过30-50行）？
- [ ] 访问修饰符使用是否合理（最小权限原则）？
- [ ] 是否使用了有意义的命名？

```csharp
public enum Currency { CNY, USD, EUR }

public class Transaction
{
    public DateTime Time { get; }
    public decimal Amount { get; }
    public string Type { get; }  // "存款" or "取款"
    public decimal BalanceAfter { get; }

    public Transaction(decimal amount, string type, decimal balanceAfter)
    {
        Time = DateTime.Now;
        Amount = amount;
        Type = type;
        BalanceAfter = balanceAfter;
    }
}

public class AdvancedBankAccount
{
    private decimal _balance;
    private readonly Currency _currency;
    private readonly List<Transaction> _transactions;
    private const decimal AnnualInterestRate = 0.035m;  // 3.5%年利率

    public string AccountNumber { get; }
    public string OwnerName { get; }
    public decimal Balance => _balance;
    public Currency AccountCurrency => _currency;
    public IReadOnlyList<Transaction> Transactions => _transactions.AsReadOnly();


    public AdvancedBankAccount(string accountNumber, string ownerName,
                               Currency currency = Currency.CNY, decimal initialDeposit = 0)
    {
        AccountNumber = accountNumber;
        OwnerName = ownerName;
        _currency = currency;
        _balance = initialDeposit;
        _transactions = new List<Transaction>();

        if (initialDeposit > 0)
        {
            RecordTransaction(initialDeposit, "初始存款");
        }
    }

    public void Deposit(decimal amount)
    {
        if (amount <= 0) throw new ArgumentException("金额必须大于0");

        _balance += amount;
        RecordTransaction(amount, "存款");
        Console.WriteLine($"[存款] +{GetCurrencySymbol()}{amount:F2}，余额: {GetCurrencySymbol()}{_balance:F2}");
    }

    public bool Withdraw(decimal amount)
    {
        if (amount <= 0)
        {
            Console.WriteLine("[取款] 金额无效");
            return false;
        }

        if (amount > _balance)
        {
            Console.WriteLine($"[取款] 余额不足");
            return false;
        }

        _balance -= amount;
        RecordTransaction(-amount, "取款");
        Console.WriteLine($"[取款] -{GetCurrencySymbol()}{amount:F2}，余额: {GetCurrencySymbol()}{_balance:F2}");
        return true;
    }

    public decimal CalculateMonthlyInterest(int year, int month)
    {
        var monthTransactions = _transactions
            .Where(t => t.Time.Year == year && t.Time.Month == month)
            .ToList();

        if (!monthTransactions.Any()) return 0;

        // 简化计算：按月末余额计算利息
        decimal avgBalance = monthTransactions.Last().BalanceAfter;
        decimal monthlyInterest = avgBalance * (AnnualInterestRate / 12);

        return Math.Round(monthlyInterest, 2);
    }

    public void PrintStatement(int year, int month)
    {
        Console.WriteLine($"\n{'=',55}");
        Console.WriteLine($"  账户流水单 - {OwnerName}");
        Console.WriteLine($"  账号: {AccountNumber} | 货币: {_currency}");
        Console.WriteLine($"  期间: {year}年{month}月");
        Console.WriteLine($"{'=',55}");

        var monthlyTransactions = _transactions
            .Where(t => t.Time.Year == year && t.Time.Month == month)
            .OrderBy(t => t.Time)
            .ToList();

        decimal interest = CalculateMonthlyInterest(year, month);

        foreach (var txn in monthlyTransactions)
        {
            string sign = txn.Amount >= 0 ? "+" : "-";
            Console.WriteLine($"{txn.Time:MM-dd HH:mm}  " +
                            $"{txn.Type,-6}  " +
                            $"{sign}{Math.Abs(txn.Amount),10:F2}  |  " +
                            $"{GetCurrencySymbol()}{txn.BalanceAfter,12:F2}");
        }

        Console.WriteLine($"{'-',55}");
        Console.WriteLine($"本月利息 (+): {GetCurrencySymbol()}{interest:F2}");
        Console.WriteLine($"期末余额:     {GetCurrencySymbol()}{(_balance + interest):F2}");
        Console.WriteLine($"{'=',55}");
    }

    private void RecordTransaction(decimal amount, string type)
    {
        _transactions.Add(new Transaction(amount, type, _balance));
    }

    private string GetCurrencySymbol() => _currency switch
    {
        Currency.CNY => "¥",
        Currency.USD => "$",
        Currency.EUR => "€",
        _ => ""
    };
}
```

<summary>查看答案</summary>

```csharp
public enum Profession
{
    Warrior,    // 战士：高血量，低魔法
    Mage,       // 法师：低血量，高魔法
    Archer      // 弓箭手：平衡型
}

public class GameCharacter
{
    public string Name { get; private set; }
    public Profession Profession { get; private set; }
    public int Level { get; private set; }
    public int Experience { get; private set; }

    private int _maxHealth;
    private int _currentHealth;
    private int _maxMana;
    private int _currentMana;
    private int _attackPower;
    private int _defensePower;


    public GameCharacter(string name, Profession profession)
    {
        Name = name;
        Profession = profession;
        Level = 1;
        Experience = 0;

        // 根据职业设置初始属性
        switch (profession)
        {
            case Profession.Warrior:
                _maxHealth = 150;
                _maxMana = 30;
                _attackPower = 15;
                _defensePower = 10;
                break;
            case Profession.Mage:
                _maxHealth = 80;
                _maxMana = 150;
                _attackPower = 25;
                _defensePower = 5;
                break;
            case Profession.Archer:
                _maxHealth = 110;
                _maxMana = 70;
                _attackPower = 20;
                _defensePower = 7;
                break;
        }

        _currentHealth = _maxHealth;
        _currentMana = _maxMana;
    }

    // 只读属性
    public int Health => _currentHealth;
    public int MaxHealth => _maxHealth;
    public int Mana => _currentMana;
    public int MaxMana => _maxMana;
    public bool IsAlive => _currentHealth > 0;
    public bool CanCastSpell => _currentMana >= 20;
    public float HealthPercentage => (float)_currentHealth / _maxHealth * 100;


    public int Attack(GameCharacter target)
    {
        if (!IsAlive)
        {
            Console.WriteLine($"{Name} 已经倒下，无法攻击！");
            return 0;
        }

        // 计算伤害（考虑目标防御力）
        int damage = Math.Max(1, _attackPower - target._defensePower / 2);
        Random random = new Random();
        damage = (int)(damage * (random.NextDouble() * 0.4 + 0.8));  // 80%-120%浮动

        target.TakeDamage(damage, this);

        // 普通攻击消耗少量魔法
        _currentMana = Math.Max(0, _currentMana - 2);

        Console.WriteLine($"{Name} 攻击了 {target.Name}，造成 {damage} 点伤害！");

        return damage;
    }

    public void TakeDamage(int damage, GameCharacter attacker)
    {
        _currentHealth = Math.Max(0, _currentHealth - damage);

        if (!IsAlive)
        {
            Console.WriteLine($"{Name} 被 {attacker.Name} 击倒了！💀");
            attacker.GainExperience(Level * 20);  // 击败奖励经验
        }
    }

    public void Heal(int healAmount)
    {
        if (!IsAlive)
        {
            Console.WriteLine($"{Name} 已经倒下，无法治疗！");
            return;
        }

        int actualHeal = Math.Min(healAmount, _maxHealth - _currentHealth);
        _currentHealth += actualHeal;

        Console.WriteLine($"{Name} 恢复了 {actualHeal} 点生命值 ({_currentHealth}/{_maxHealth}) 💚");
    }

    public bool CastSpell(GameCharacter target, int manaCost = 20)
    {
        if (!CanCastSpell)
        {
            Console.WriteLine($"{Name} 魔法值不足，无法施法！（需要{manaCost}，当前{_currentMana}）");
            return false;
        }

        _currentMana -= manaCost;
        int spellDamage = _attackPower * 2;  // 法术伤害翻倍
        target.TakeDamage(spellDamage, this);

        Console.WriteLine($"{Name} 对 {target.Name} 施放了法术，造成 {spellDamage} 点魔法伤害！✨");

        return true;
    }

    public void GainExperience(int exp)
    {
        Experience += exp;
        Console.WriteLine($"{Name} 获得 {exp} 点经验值 (总计: {Experience})");

        // 检查升级
        int expNeeded = Level * 100;
        while (Experience >= expNeeded)
        {
            Experience -= expNeeded;
            LevelUp();
            expNeeded = Level * 100;
        }
    }

    private void LevelUp()
    {
        Level++;

        // 提升属性
        _maxHealth += 20;
        _maxMana += 10;
        _attackPower += 5;
        _defensePower += 2;

        // 升级恢复满状态
        _currentHealth = _maxHealth;
        _currentMana = _maxMana;

        Console.WriteLine($"\n🎉 {Name} 升级了！现在是 {Level} 级！");
        Console.WriteLine($"   生命值: {_maxHealth} | 魔法值: {_maxMana}");
        Console.WriteLine($"   攻击力: {_attackPower} | 防御力: {_defensePower}");
    }

    public void DisplayStatus()
    {
        string professionEmoji = Profession switch
        {
            Profession.Warrior => "⚔️",
            Profession.Mage => "🧙",
            Profession.Archer => "🏹",
            _ => "❓"
        };

        Console.WriteLine($"\n{'=',45}");
        Console.WriteLine($"  {professionEmoji} {Name} (Lv.{Level} {Profession})");
        Console.WriteLine($"{'=',45}");

        // 血条
        string healthBar = GenerateBar(_currentHealth, _maxHealth, '█', '░', ConsoleColor.Red);
        string manaBar = GenerateBar(_currentMana, _maxMana, '█', '░', ConsoleColor.Blue);

        Console.WriteLine($"HP: {healthBar} {_currentHealth}/{_maxHealth}");
        Console.WriteLine($"MP: {manaBar} {_currentMana}/{_maxMana}");
        Console.WriteLine($"ATK: {_attackPower} | DEF: {_defensePower}");
        Console.WriteLine($"EXP: {Experience}/{Level * 100}");
        Console.WriteLine($"状态: {(IsAlive ? "存活 ✓" : "死亡 ✗")}");
        Console.WriteLine($"{'=',45}");
    }

    private string GenerateBar(int current, int max, char full, char empty, ConsoleColor color)
    {
        int barLength = 20;
        int filled = (int)((float)current / max * barLength);

        Console.ForegroundColor = color;
        string bar = new string(full, filled) + new string(empty, barLength - filled);
        Console.ResetColor();

        return bar;
    }
}
```

<details>
<summary>查看答案</summary>

```csharp
public enum PlayMode
{
    Sequential,  // 顺序播放
    Shuffle,     // 随机播放
    RepeatOne    // 单曲循环
}

public class Song
{
    public string Title { get; }
    public string Artist { get; }
    public string Album { get; }
    public TimeSpan Duration { get; }

    public Song(string title, string artist, string album, int durationSeconds)
    {
        Title = title;
        Artist = artist;
        Album = album;
        Duration = TimeSpan.FromSeconds(durationSeconds);
    }

    public override string ToString() => $"{Artist} - {Title}";
}

public class MusicPlayer
{
    private List<Song> _playlist;
    private int _currentIndex;
    private PlayMode _playMode;
    private int _volume;
    private bool _isPlaying;
    private Song _currentSong;


    public MusicPlayer()
    {
        _playlist = new List<Song>();
        _currentIndex = -1;
        _playMode = PlayMode.Sequential;
        _volume = 70;
        _isPlaying = false;
        _currentSong = null;
    }

    // 只读属性
    public int SongCount => _playlist.Count;
    public int Volume
    {
        get => _volume;
        set => _volume = Math.Clamp(value, 0, 100);
    }
    public PlayMode CurrentMode => _playMode;
    public bool IsPlaying => _isPlaying;
    public Song CurrentSong => _currentSong;


    public void AddSong(Song song)
    {
        _playlist.Add(song);
        Console.WriteLine($"🎵 已添加: {song}");

        // 如果是第一首歌，自动选中
        if (_playlist.Count == 1)
        {
            _currentIndex = 0;
            _currentSong = _playlist[0];
        }
    }

    public void RemoveSong(int index)
    {
        if (index < 0 || index >= _playlist.Count)
        {
            Console.WriteLine("无效的歌曲索引");
            return;
        }

        var removed = _playlist[index];
        _playlist.RemoveAt(index);
        Console.WriteLine($"🗑️  已移除: {removed}");

        // 调整当前索引
        if (_playlist.Count == 0)
        {
            _currentIndex = -1;
            _currentSong = null;
            _isPlaying = false;
        }
        else if (index < _currentIndex)
        {
            _currentIndex--;
        }
        else if (index == _currentIndex)
        {
            _currentIndex = Math.Min(_currentIndex, _playlist.Count - 1);
            _currentSong = _playlist[_currentIndex];
        }
    }

    public void ClearPlaylist()
    {
        _playlist.Clear();
        _currentIndex = -1;
        _currentSong = null;
        _isPlaying = false;
        Console.WriteLine("📋 播放列表已清空");
    }

    public void Play()
    {
        if (_playlist.Count == 0)
        {
            Console.WriteLine("播放列表为空");
            return;
        }

        if (_currentIndex == -1)
            _currentIndex = 0;

        _currentSong = _playlist[_currentIndex];
        _isPlaying = true;

        Console.WriteLine($"\n▶️  正在播放: {_currentSong}");
        Console.WriteLine($"   专辑: {_currentSong.Album}");
        Console.WriteLine($"   时长: {_currentSong.Duration:mm\\:ss}");
        Console.WriteLine($"   音量: {Volume}% | 模式: {_playMode}");
    }

    public void Pause()
    {
        if (!_isPlaying)
        {
            Console.WriteLine("没有正在播放的音乐");
            return;
        }

        _isPlaying = false;
        Console.WriteLine($"⏸️  已暂停: {_currentSong}");
    }

    public void Stop()
    {
        _isPlaying = false;
        _currentIndex = 0;
        Console.WriteLine("⏹️  停止播放");
    }

    public void Next()
    {
        if (_playlist.Count == 0) return;

        switch (_playMode)
        {
            case PlayMode.Sequential:
                _currentIndex = (_currentIndex + 1) % _playlist.Count;
                break;
            case PlayMode.Shuffle:
                Random random = new Random();
                _currentIndex = random.Next(_playlist.Count);
                break;
            case PlayMode.RepeatOne:
                // 保持当前歌曲不变
                break;
        }

        _currentSong = _playlist[_currentIndex];

        if (_isPlaying)
            Play();
        else
            Console.WriteLine($"⏭️  下一首: {_currentSong}");
    }

    public void Previous()
    {
        if (_playlist.Count == 0) return;

        _currentIndex = _currentIndex <= 0 ? _playlist.Count - 1 : _currentIndex - 1;
        _currentSong = _playlist[_currentIndex];

        if (_isPlaying)
            Play();
        else
            Console.WriteLine($"⏮️  上一首: {_currentSong}");
    }

    public void TogglePlayMode()
    {
        _playMode = _playMode switch
        {
            PlayMode.Sequential => PlayMode.Shuffle,
            PlayMode.Shuffle => PlayMode.RepeatOne,
            PlayMode.RepeatOne => PlayMode.Sequential,
            _ => PlayMode.Sequential
        };

        Console.WriteLine($"播放模式切换为: {_playMode}");
    }

    public void DisplayPlaylist()
    {
        Console.WriteLine($"\n{'=',50}");
        Console.WriteLine($"  🎵 播放列表 ({_playlist.Count}首)");
        Console.WriteLine($"  模式: {_playMode} | 音量: {Volume}%");
        Console.WriteLine($"{'=',50}");

        for (int i = 0; i < _playlist.Count; i++)
        {
            string marker = i == _currentIndex ? "▶️ " : "   ";
            string playing = (i == _currentIndex && _isPlaying) ? " [播放中]" : "";
            Console.WriteLine($"{marker}{i + 1}. {_playlist[i]}{playing}");
        }
    }

    public void DisplayNowPlaying()
    {
        if (_currentSong == null)
        {
            Console.WriteLine("当前没有播放任何歌曲");
            return;
        }

        Console.WriteLine($"\n🎶 正在{( _isPlaying ? "播放" : "暂停")}: {_currentSong}");
        Console.WriteLine($"   歌手: {_currentSong.Artist}");
        Console.WriteLine($"   专辑: {_currentSong.Album}");
        Console.WriteLine($"   时长: {_currentSong.Duration:mm\\:ss}");
        Console.WriteLine($"   音量: {"█".Repeat(Volume / 5)}{"░".Repeat(20 - Volume / 5)} {Volume}%");
    }
}

var player = new MusicPlayer();
```

```csharp
public class Question
{
    public int Id { get; }
    public string Content { get; }
    public string[] Options { get; }
    public int CorrectAnswerIndex { get; }  // 正确选项的索引（0-based）
    public int Points { get; }

    public Question(int id, string content, string[] options, int correctAnswer, int points)
    {
        Id = id;
        Content = content;
        Options = options;
        CorrectAnswerIndex = correctAnswer;
        Points = points;
    }

    public void Display()
    {
        Console.WriteLine($"\n【第{Id}题】{Content}（{Points}分）");

        for (int i = 0; i < Options.Length; i++)
        {
            Console.WriteLine($"  {Convert.ToChar('A' + i)}. {Options[i]}");
        }
    }

    public bool CheckAnswer(int answerIndex)
    {
        return answerIndex == CorrectAnswerIndex;
    }
}

public class Exam
{
    public string Title { get; }
    public int DurationMinutes { get; }
    public List<Question> Questions { get; }
    public int TotalPoints => Questions.Sum(q => q.Points);

    public Exam(string title, int durationMinutes)
    {
        Title = title;
        DurationMinutes = durationMinutes;
        Questions = new List<Question>();
    }

    public void AddQuestion(Question question)
    {
        Questions.Add(question);
    }

    public void DisplayExamInfo()
    {
        Console.WriteLine($"\n{'=',55}");
        Console.WriteLine($"  📝 {Title}");
        Console.WriteLine($"{'=',55}");
        Console.WriteLine($"  题目数量: {Questions.Count}道");
        Console.WriteLine($"  总分: {TotalPoints}分");
        Console.WriteLine($"  考试时长: {DurationMinutes}分钟");
        Console.WriteLine($"{'=',55}");
    }
}

public class StudentExam
{
    public string StudentName { get; }
    public Exam Exam { get; }
    private Dictionary<int, int> _answers;  // 题目ID -> 学生答案索引
    private DateTime _startTime;
    private DateTime? _submitTime;
    private bool _submitted;


    public StudentExam(string studentName, Exam exam)
    {
        StudentName = studentName;
        Exam = exam;
        _answers = new Dictionary<int, int>();
        _submitted = false;
    }

    public void StartExam()
    {
        _startTime = DateTime.Now;
        Console.WriteLine($"\n🕐 考试开始时间: {_startTime:HH:mm:ss}");
        Console.WriteLine($"⏱️  请在 {Exam.DurationMinutes} 分钟内完成\n");
    }

    public void AnswerQuestion(int questionId, int answerIndex)
    {
        if (_submitted)
        {
            Console.WriteLine("考试已提交，不能再作答");
            return;
        }

        var question = Exam.Questions.FirstOrDefault(q => q.Id == questionId);
        if (question == null)
        {
            Console.WriteLine($"找不到ID为 {questionId} 的题目");
            return;
        }

        if (answerIndex < 0 || answerIndex >= question.Options.Length)
        {
            Console.WriteLine("无效的答案选项");
            return;
        }

        _answers[questionId] = answerIndex;
        Console.WriteLine($"✓ 第{questionId}题已作答: {Convert.ToChar('A' + answerIndex)}");
    }

    public ExamResult Submit()
    {
        if (_submitted)
        {
            Console.WriteLine("考试已经提交过了");
            return null;
        }

        _submitTime = DateTime.Now;
        _submitted = true;

        // 评分
        int earnedPoints = 0;
        var results = new List<(Question Question, bool IsCorrect)>();

        foreach (var question in Exam.Questions)
        {
            bool answered = _answers.ContainsKey(question.Id);
            bool isCorrect = answered && question.CheckAnswer(_answers[question.Id]);

            if (isCorrect)
                earnedPoints += question.Points;

            results.Add((question, isCorrect));
        }

        TimeSpan timeTaken = _submitTime.Value - _startTime;
        bool passed = earnedPoints >= Exam.TotalPoints * 0.6;  // 及格线60%

        var result = new ExamResult
        {
            StudentName = StudentName,
            ExamTitle = Exam.Title,
            TotalPoints = Exam.TotalPoints,
            EarnedPoints = earnedPoints,
            Score = (double)earnedPoints / Exam.TotalPoints * 100,
            TimeTaken = timeTaken,
            Passed = passed,
            SubmitTime = _submitTime.Value,
            Details = results
        };

        return result;
    }
}

public class ExamResult
{
    public string StudentName { get; set; }
    public string ExamTitle { get; set; }
    public int TotalPoints { get; set; }
    public int EarnedPoints { get; set; }
    public double Score { get; set; }
    public TimeSpan TimeTaken { get; set; }
    public bool Passed { get; set; }
    public DateTime SubmitTime { get; set; }
    public List<(Question Question, bool IsCorrect)> Details { get; set; }

    public void DisplayResult()
    {
        Console.WriteLine($"\n{'=',60}");
        Console.WriteLine($"  📊 考试成绩单");
        Console.WriteLine($"{'=',60}");
        Console.WriteLine($"  学生: {StudentName}");
        Console.WriteLine($"  科目: {ExamTitle}");
        Console.WriteLine($"  提交时间: {SubmitTime:yyyy-MM-dd HH:mm:ss}");
        Console.WriteLine($"  用时: {TimeTaken.Minutes}分{timeTaken.Seconds}秒");
        Console.WriteLine($"{'-',60}");
        Console.WriteLine($"  得分: {EarnedPoints}/{TotalPoints} ({Score:F1}分)");
        Console.WriteLine($"  结果: {(Passed ? "✅ 通过" : "❌ 未通过")}");
        Console.WriteLine($"{'-',60}");

        Console.WriteLine("\n  答题详情:");

        foreach (var (question, isCorrect) in Details)
        {
            string icon = isCorrect ? "✓" : "✗";
            string status = isCorrect ? $"+{question.Points}分" : "0分";

            Console.WriteLine($"  {icon} 第{question.Id}题 [{status}] {question.Content.Substring(0, Math.Min(20, question.Content.Length))}...");
        }

        Console.WriteLine($"{'=',60}");
    }
}
```

## 十一、总结

面向对象编程（OOP）是现代软件开发的基石，掌握它意味着：

1. **更好的代码组织** - 用类和对象模拟现实世界
2. **更高的代码复用** - 通过继承和组合避免重复
3. **更强的封装性** - 隐藏实现细节，降低复杂度
4. **更易维护和扩展** - 符合开闭原则的设计

### 学习路线图

```
变量与数据类型 → 控制流语句 → 面向对象基础（本章）
                                    ↓
                              LINQ查询语言
                                    ↓
                              异步编程
                                    ↓
                              ASP.NET Core开发
```

### 关键要点回顾

- **类**是模板，**对象**是实例
- **属性**封装数据，**方法**封装行为
- **构造函数**负责初始化对象
- **访问修饰符**控制访问权限（最小权限原则）
- **this**引用当前对象实例
- **封装**是OOP的核心思想
