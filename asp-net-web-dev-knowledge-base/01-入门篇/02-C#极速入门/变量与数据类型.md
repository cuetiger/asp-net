## 一、为什么需要了解变量和数据类型？

在Web开发中，我们每天都在处理各种类型的数据：

- 用户注册时需要存储**用户名**（字符串）和**年龄**（整数）
- 购物车系统需要记录**商品价格**（小数）和**库存数量**（整数）
- 订单状态需要用**布尔值**表示是否已支付
- 日志系统需要记录**操作时间**（日期时间）

变量就像一个个"盒子"，用来存放不同类型的数据。而数据类型则告诉计算机这个"盒子"能装什么类型的东西、占多大空间。理解它们是编程的第一步。

## 二、常用数据类型一览表

### 2.1 值类型（基本数据类型）

| 类型 | 关键字 | 说明 | 示例 | 占用空间 |
|------|--------|------|------|----------|
| 整数 | `int` | 存储整数 | 年龄、数量 | 4字节 |
| 长整数 | `long` | 更大的整数 | 订单ID、时间戳 | 8字节 |
| 小数 | `double` | 双精度浮点数 | 价格、评分 | 8字节 |
| 小数 | `decimal` | 高精度小数 | 金额计算（推荐） | 16字节 |
| 布尔值 | `bool` | true/false | 是否登录、是否VIP | 1字节 |
| 字符 | `char` | 单个字符 | 性别代号 | 2字节 |

### 2.2 引用类型

| 类型 | 关键字 | 说明 | 示例 |
|------|--------|------|------|
| 字符串 | `string` | 文本序列 | 用户名、地址 |
| 日期时间 | `DateTime` | 时间和日期 | 注册时间、订单日期 |
| 对象 | `object` | 所有类型的基类 | 任意类型 |

### 💡 Web开发小贴士：
处理金钱金额时，**务必使用`decimal`而不是`double`**！因为`decimal`不会出现精度丢失问题。

```csharp
// 错误示例：使用double可能导致精度问题
double price1 = 0.1 + 0.2;  // 结果可能是 0.30000000000000004

// 正确示例：使用decimal保证精确
decimal price2 = 0.1m + 0.2m;  // 结果精确为 0.3
```

## 四、变量命名规范

良好的命名习惯让代码更易读、更专业！

### 4.1 命名规则

```csharp
// ✅ 正确的命名方式
int userAge = 25;                    // camelCase：局部变量、参数
string userName = "张三";             // camelCase
decimal totalPrice = 1999.99m;        // camelCase：多个单词拼接
bool isDeleted = false;               // 布尔值用is/has/can开头
DateTime createdAt = DateTime.Now;    // 时间用At/On结尾

// ❌ 错误的命名方式
int a = 25;                          // 太简单，含义不明
string name1 = "张三";                // 数字后缀不推荐
int Age = 25;                        // 局部变量不应使用PascalCase
string my-variable = "test";         // 不能包含连字符
```

### 4.2 命名规范速查表

| 场景 | 规范 | 示例 |
|------|------|------|
| 局部变量/参数 | camelCase | `userName`, `userAge` |
| 公共属性/方法 | PascalCase | `UserName`, `GetUser()` |
| 私有字段 | _camelCase | `_userName`, `_connectionString` |
| 常量 | PascalCase | `MaxRetryCount`, `DefaultTimeout` |
| 布尔变量 | is/has/can前缀 | `isValid`, `hasPermission` |

### 4.3 Web开发中的实际案例

```csharp
public class UserController
{
    // ✅ 优秀的命名示例
    private string _connectionString;          // 私有字段：_camelCase
    public int MaxLoginAttempts { get; } = 5;  // 公共常量属性：PascalCase

    public void Login(string userName, string password)  // 参数：camelCase
    {
        int attemptCount = 0;                // 局部变量：camelCase
        bool isAuthenticated = false;        // 布尔值：is前缀
        DateTime loginTime = DateTime.Now;   // 时间：At结尾
        TimeSpan timeout = TimeSpan.FromMinutes(30);  // 有意义的名称

        // 业务逻辑...
    }
}
```

## 五、类型转换

在Web开发中，我们经常需要在不同数据类型之间转换，比如将用户输入的字符串转换为数字。

### 5.1 隐式转换（安全，自动进行）

```csharp
int age = 25;
long bigNumber = age;           // int → long（小范围→大范围，安全）
double price = 100;            // int → double（自动转换）

Console.WriteLine(bigNumber);  // 输出: 25
Console.WriteLine(price);      // 输出: 100
```

### 5.2 显式转换（强制转换，可能丢失数据）

```csharp
double score = 95.5;
int finalScore = (int)score;    // 强制转换，会截断小数部分

Console.WriteLine(finalScore);  // 输出: 95（丢失了0.5）
```

### 5.3 Convert类转换（推荐用于字符串转换）

```csharp
// 从字符串转换为其他类型
string strAge = "25";
string strPrice = "1999.99";
string strBool = "true";

int age = Convert.ToInt32(strAge);
decimal price = Convert.ToDecimal(strPrice);
bool isActive = Convert.ToBoolean(strBool);

Console.WriteLine($"年龄: {age}, 价格: {price}, 激活: {isActive}");
```

### 5.4 Parse和TryParse（最常用的字符串转换）

```csharp
// Parse方法：转换失败会抛异常
string input1 = "100";
int number1 = int.Parse(input1);     // 成功
// int number2 = int.Parse("abc");   // 抛出FormatException异常！

// TryParse方法：更安全，返回是否成功
string input2 = "200";
string input3 = "不是数字";

bool success1 = int.TryParse(input2, out int result1);
bool success2 = int.TryParse(input3, out int result2);

Console.WriteLine($"转换1成功: {success1}, 结果: {result1}");  // True, 200
Console.WriteLine($"转换2成功: {success2}, 结果: {result2}");  // False, 0
```

### 5.5 实战示例：处理用户输入

```csharp
// 场景：用户在网页表单提交的数据都是字符串，我们需要验证和转换
public class OrderService
{
    public void CreateOrder(string userIdStr, string quantityStr,
                           string priceStr, string discountStr)
    {
        // 1. 转换用户ID
        if (!int.TryParse(userIdStr, out int userId))
        {
            Console.WriteLine("错误：用户ID必须是数字");
            return;
        }

        // 2. 转换购买数量
        if (!int.TryParse(quantityStr, out int quantity) || quantity <= 0)
        {
            Console.WriteLine("错误：数量必须是正整数");
            return;
        }

        // 3. 转换价格（金额必须用decimal）
        if (!decimal.TryParse(priceStr, out decimal price) || price <= 0)
        {
            Console.WriteLine("错误：价格必须是正数");
            return;
        }

        // 4. 转换折扣率（可选字段）
        decimal discount = 0;
        if (!string.IsNullOrEmpty(discountStr))
        {
            if (!decimal.TryParse(discountStr, out discount) ||
                discount < 0 || discount > 1)
            {
                Console.WriteLine("错误：折扣必须在0-1之间");
                return;
            }
        }

        // 5. 计算最终价格
        decimal finalPrice = price * quantity * (1 - discount);

        // 6. 创建订单
        Console.WriteLine("=== 订单创建成功 ===");
        Console.WriteLine($"用户ID: {userId}");
        Console.WriteLine($"数量: {quantity}");
        Console.WriteLine($"单价: ¥{price:F2}");
        Console.WriteLine($"折扣: {discount:P0}");          // P0表示百分比格式
        Console.WriteLine($"总价: ¥{finalPrice:F2}");
        Console.WriteLine($"下单时间: {DateTime.Now:yyyy-MM-dd HH:mm:ss}");
    }
}

// 测试调用
var service = new OrderService();
service.CreateOrder("1001", "2", "2999.99", "0.1");  // 有效输入
Console.WriteLine();
service.CreateOrder("abc", "2", "2999.99", "0.1");   // 无效的用户ID
```

### 5.6 ToString()方法（转换为字符串）

```csharp
int number = 12345;
decimal money = 12345.6789m;
DateTime now = DateTime.Now;
bool flag = true;

// 基本转换
Console.WriteLine(number.ToString());              // "12345"
Console.WriteLine(money.ToString());               // "12345.6789"
Console.WriteLine(now.ToString());                 // 完整日期时间
Console.WriteLine(flag.ToString());                // "True"

// 格式化输出（非常重要！）
Console.WriteLine(number.ToString("N2"));          // "12,345.00" (千分位)
Console.WriteLine(number.ToString("C"));           // "¥12,345.00" (货币格式)
Console.WriteLine(money.ToString("F2"));           // "12345.68" (固定2位小数)
Console.WriteLine(now.ToString("yyyy-MM-dd"));     // "2024-01-15"
Console.WriteLine(now.ToString("HH:mm:ss"));       // "14:30:25"
```

## 六、可空类型

在实际业务中，有些字段可能没有值（比如用户的中间名、可选的电话号码）。C#提供了可空类型来处理这种情况。

### 6.1 声明可空类型

```csharp
// 值类型默认不能为null
int age = 25;           // 必须有值
// int age2 = null;     // 编译错误！

// 使用可空类型（在类型后加?）
int? age2 = null;       // 可以是null
int? age3 = 25;         // 也可以有值
decimal? salary = null; // 可空的薪水
DateTime? birthday = null; // 可空的生日
```

### 6.2 判断和使用可空类型

```csharp
int? testScore = null;

// 方式一：HasValue和Value属性
if (testScore.HasValue)
{
    Console.WriteLine($"分数: {testScore.Value}");
}
else
{
    Console.WriteLine("暂无分数");
}

// 方式二：Null合并运算符??（推荐）
int actualScore = testScore ?? 0;  // 如果是null则使用默认值0
Console.WriteLine($"实际分数: {actualScore}");

// 方式三：Null条件运算符?.
string? middleName = null;
int length = middleName?.Length ?? 0;  // 安全访问，避免NullReferenceException
Console.WriteLine($"中间名长度: {length}");
```

### 6.3 实际应用场景

```csharp
public class UserProfile
{
    public int UserId { get; set; }
    public string UserName { get; set; }
    public string? NickName { get; set; }        // 可选的昵称
    public string? AvatarUrl { get; set; }       // 可选的头像URL
    public DateTime? LastLoginTime { get; set; } // 可能从未登录
    public decimal? MonthlyIncome { get; set; }  // 可选的收入信息

    public void DisplayInfo()
    {
        Console.WriteLine($"=== 用户资料 ===");
        Console.WriteLine($"ID: {UserId}");
        Console.WriteLine($"用户名: {UserName}");

        // 使用可空类型的安全处理
        Console.WriteLine($"昵称: {NickName ?? "未设置"}");

        if (AvatarUrl != null)
        {
            Console.WriteLine($"头像: {AvatarUrl}");
        }
        else
        {
            Console.WriteLine("头像: 未上传");
        }

        // Null合并运算符简化代码
        Console.WriteLine($"最后登录: {LastLoginTime?.ToString("yyyy-MM-dd HH:mm") ?? "从未登录"}");
        Console.WriteLine($"月收入: {(MonthlyIncome.HasValue ? $"¥{MonthlyIncome.Value:N0}" : "未填写")}");
    }
}

// 使用示例
var user = new UserProfile
{
    UserId = 1001,
    UserName = "zhangsan",
    NickName = "小明",
    AvatarUrl = null,                      // 未设置头像
    LastLoginTime = null,                   // 从未登录
    MonthlyIncome = 25000.00m              // 已填写收入
};
user.DisplayInfo();
```

## 七、const和readonly（常量）

有些值在程序运行过程中永远不会改变，比如税率、最大重试次数等。

### 7.1 const（编译时常量）

```csharp
class Constants
{
    // 编译时就必须确定值，且不能修改
    public const double TaxRate = 0.13;           // 税率13%
    public const int MaxPasswordLength = 20;      // 密码最大长度
    public const string AppName = "MyWebApp";     // 应用名称
    public const int DefaultPageSize = 20;        // 默认分页大小

    public void CalculateTax(decimal amount)
    {
        decimal tax = amount * (decimal)TaxRate;
        Console.WriteLine($"税额: ¥{tax:F2}");

        // TaxRate = 0.15;  // 编译错误！不能修改const
    }
}
```

### 7.2 readonly（运行时常量）

```csharp
class Configuration
{
    // 可以在构造函数中赋值，之后不能修改
    public readonly string ConnectionString;
    public readonly int MaxConnections;
    public readonly DateTime CreatedAt;

    public Configuration(string connectionString, int maxConnections)
    {
        ConnectionString = connectionString;  // 构造函数中赋值
        MaxConnections = maxConnections;
        CreatedAt = DateTime.Now;
    }

    public void Test()
    {
        Console.WriteLine(ConnectionString);
        // ConnectionString = "new connection";  // 编译错误！不能修改readonly
    }
}
```

## 八、总结与最佳实践

### 8.1 数据类型选择指南

| 场景 | 推荐类型 | 原因 |
|------|----------|------|
| 年龄、数量、计数 | `int` | 最常用的整数类型 |
| 金额、价格 | `decimal` | 精度高，不会丢失精度 |
| 科学计算、百分比 | `double` | 范围大，性能好 |
| 是/否判断 | `bool` | 语义清晰 |
| 文本内容 | `string` | Unicode支持 |
| 时间日期 | `DateTime` | 功能丰富 |
| 大ID、时间戳 | `long` | 范围更大 |
| 可选字段 | `T?` | 支持null值 |

### 8.2 代码质量检查清单

- [ ] 变量命名是否有意义（避免a, b, temp）
- [ ] 是否遵循了camelCase/PascalCase规范
- [ ] 金额是否使用了`decimal`而不是`double`
- [ ] 字符串转换是否使用了`TryParse`而不是`Parse`
- [ ] 可选字段是否使用了可空类型`T?`
- [ ] 不变的值是否定义为了`const`或`readonly`
- [ ] 数值输出是否使用了合适的格式化（货币、百分比等）

### 练习2：类型转换练习
**题目**：编写一个方法，接收用户输入的字符串（商品价格和折扣率），计算折后价格。要求处理各种无效输入情况。

<details>
<summary>查看答案</summary>

```csharp
public void CalculateDiscountedPrice(string priceStr, string discountStr)
{
    // 验证价格
    if (!decimal.TryParse(priceStr, out decimal price) || price <= 0)
    {
        Console.WriteLine("错误：请输入有效的正数价格");
        return;
    }

    // 验证折扣（可选）
    decimal discount = 0;
    if (!string.IsNullOrWhiteSpace(discountStr))
    {
        if (!decimal.TryParse(discountStr, out discount) ||
            discount < 0 || discount > 1)
        {
            Console.WriteLine("错误：折扣必须在0到1之间（如0.2表示8折）");
            return;
        }
    }

    // 计算结果
    decimal finalPrice = price * (1 - discount);
    decimal savedAmount = price * discount;

    Console.WriteLine("=== 折扣计算结果 ===");
    Console.WriteLine($"原价: ¥{price:F2}");
    Console.WriteLine($"折扣: {discount:P0}");
    Console.WriteLine($"优惠: ¥{savedAmount:F2}");
    Console.WriteLine($"现价: ¥{finalPrice:F2}");
}

// 测试
CalculateDiscountedPrice("299.99", "0.2");    // 正常情况
CalculateDiscountedPrice("-100", "0.5");      // 无效价格
CalculateDiscountedPrice("500", "1.5");       // 无效折扣
```
</details>

### 练习4：综合实战 - 购物车计算器
**题目**：模拟一个简单的购物车结算系统。购物车中有多个商品，每个商品有名称、单价、数量。计算总金额，并根据总金额给予折扣（满100减10，满200减30，满500减80）。输出详细的购物清单和结算信息。

<details>
<summary>查看答案</summary>

```csharp
public class ShoppingCartCalculator
{
    public const decimal Discount100 = 10m;
    public const decimal Discount200 = 30m;
    public const decimal Discount500 = 80m;

    public void Calculate(List<(string Name, decimal Price, int Quantity)> items)
    {
        decimal subtotal = 0;

        Console.WriteLine("==============================");
        Console.WriteLine("        购物车结算单");
        Console.WriteLine("==============================");
        Console.WriteLine($"{"商品名称",-12} {"单价",10} {"数量",6} {"小计",12}");
        Console.WriteLine("----------------------------------------------");

        foreach (var item in items)
        {
            decimal itemTotal = item.Price * item.Quantity;
            subtotal += itemTotal;

            Console.WriteLine($"{item.Name,-12} ¥{item.Price,8:F2} x{item.Quantity,3} ¥{itemTotal,10:F2}");
        }

        Console.WriteLine("----------------------------------------------");
        Console.WriteLine($"{"商品总计:",28} ¥{subtotal,10:F2}");

        // 计算折扣
        decimal discount = subtotal >= 500 ? Discount500 :
                          subtotal >= 200 ? Discount200 :
                          subtotal >= 100 ? Discount100 : 0;

        if (discount > 0)
        {
            Console.WriteLine($"{"优惠减免:",28} -¥{discount,9:F2}");
        }

        decimal total = subtotal - discount;
        Console.WriteLine("----------------------------------------------");
        Console.WriteLine($"{"应付总额:",28} ¥{total,10:F2}");
        Console.WriteLine("==============================");
        Console.WriteLine($"结算时间: {DateTime.Now:yyyy-MM-dd HH:mm:ss}");
        Console.WriteLine();
    }
}
```

### 练习5：进阶挑战 - 格式化工具类
**题目**：创建一个通用的格式化工具类，提供以下功能：
1. 格式化金额（添加千分位和人民币符号）
2. 格式化日期（支持多种模式）
3. 格式化手机号（隐藏中间四位：138****8000）
4. 格式化文件大小（B、KB、MB、GB自动转换）

<details>
<summary>查看答案</summary>

```csharp
public static class FormatHelper
{
    // 格式化金额
    public static string FormatMoney(decimal amount)
    {
        return amount.ToString("C", new System.Globalization.CultureInfo("zh-CN"));
    }

    // 格式化日期
    public static string FormatDate(DateTime date, string pattern = "yyyy-MM-dd")
    {
        return date.ToString(pattern);
    }

    // 格式化手机号
    public static string MaskPhoneNumber(string phone)
    {
        if (string.IsNullOrEmpty(phone) || phone.Length < 11)
            return phone ?? "";

        return phone.Substring(0, 3) + "****" + phone.Substring(7);
    }

    // 格式化文件大小
    public static string FormatFileSize(long bytes)
    {
        string[] sizes = { "B", "KB", "MB", "GB", "TB" };
        int order = 0;
        double size = bytes;

        while (size >= 1024 && order < sizes.Length - 1)
        {
            order++;
            size /= 1024;
        }

        return $"{size:F2} {sizes[order]}";
    }
}

// 测试
Console.WriteLine(FormatHelper.FormatMoney(12345.6789m));      // ¥12,345.68
Console.WriteLine(FormatHelper.FormatDate(DateTime.Now));       // 2024-01-15
Console.WriteLine(FormatHelper.MaskPhoneNumber("13800138000")); // 138****8000
Console.WriteLine(FormatHelper.FormatFileSize(1536));           // 1.50 KB
Console.WriteLine(FormatHelper.FormatFileSize(1048576));        // 1.00 MB
Console.WriteLine(FormatHelper.FormatFileSize(1073741824));     // 1.00 GB
```
