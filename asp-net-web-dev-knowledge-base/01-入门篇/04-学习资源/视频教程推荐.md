## 四、学习建议与策略

### 1. 如何选择适合自己的资源？

```
零基础 + 中文优先：
└── B站（老张的哲学、杨旭）+ Microsoft Learn中文版

有一定基础 + 想系统学习：
└── Microsoft Learn 完整路径 + Pluralsight（如有预算）

英语较好 + 追求深度：
└── YouTube（IAmTimCorey、Nick Chapsas）+ Pluralsight

时间碎片化 + 免费为主：
└── Microsoft Learn 模块化课程 + B站短视频

求职导向 + 项目驱动：
└── Udemy 实战课程 + GitHub开源项目模仿
```

### 2. 高效学习技巧

1. **边看边练**: 不要只看不动手，每学一个概念立即写代码验证
2. **调整倍速**: 熟悉的内容1.5x-2x播放，难点0.75x-1x反复观看
3. **做笔记整理**: 用Markdown或Notion记录关键知识点和代码片段
4. **加入社区**: 参与B站评论区、GitHub Discussions、QQ/Discord群组讨论
5. **项目驱动**: 以完成一个小项目为目标串联所学知识

### 3. 避免常见陷阱

- **贪多嚼不烂**: 不要同时追多个系列，专注完成一个再开始下一个
- **只看不练**: 视看了很多，但自己写不出代码 = 没学会
- **忽视基础**: 直接跳到高级话题会导致后续学习困难
- **版本过时**: 确保学习资源针对.NET 8/9或更新的版本
