# 官方文档链接

> 本文档整理微软官方ASP.NET Core学习路径，按推荐学习顺序排列，帮助您系统性地掌握.NET Web开发技术。

---

## 一、快速入门（必学优先）

### 1. ASP.NET Core 入门教程

**链接**: [https://learn.microsoft.com/zh-cn/aspnet/core/get-started?view=aspnetcore-9.0](https://learn.microsoft.com/zh-cn/aspnet/core/get-started?view=aspnetcore-9.0)

**中文说明**: 微软官方最新入门指南，使用 .NET CLI 创建、运行和修改 ASP.NET Core Blazor Web App。全程约5-10分钟即可完成第一个应用创建。

**使用建议**:
- **适合人群**: 零基础初学者，第一次接触ASP.NET Core
- **学习目标**: 理解项目创建流程、基本运行方式
- **前置要求**: 已安装 .NET SDK（推荐 .NET 8 或 9）
- **预计时长**: 15-30分钟
- **重点掌握**: `dotnet new` 命令、项目结构、如何运行和调试

### 2. 使用 ASP.NET Core 为初学者构建 Web 应用程序（完整学习路径）

**链接**: [https://learn.microsoft.com/zh-cn/training/paths/aspnet-core-web-app/](https://learn.microsoft.com/zh-cn/training/paths/aspnet-core-web-app/)

**中文说明**: Microsoft Learn 官方认证的系统性学习路径，包含C#基础、HTML、Razor Pages等多个模块，总计约900 XP经验值。

**使用建议**:
- **适合人群**: 希望系统学习的初学者
- **学习目标**: 从零到一构建完整的Web应用程序
- **模块组成**:
  - C# 编程基础
  - HTML 和 CSS 基础
  - Razor Pages 开发
  - 数据访问入门
- **预计时长**: 10-20小时（可分阶段完成）
- **证书**: 完成后可获得Microsoft Learn徽章

## 二、核心文档（深入学习）

### 3. .NET 官方文档导航

**链接**: [https://docs.microsoft.com/zh-cn/dotnet/](https://docs.microsoft.com/zh-cn/dotnet/)

**中文说明**: .NET平台的权威文档中心，涵盖.NET运行时、基础类库、开发工具等全方位内容，支持中英文切换。

**使用建议**:
- **适合人群**: 所有.NET开发者（作为案头手册）
- **核心板块**:
  - **入门指南**: [https://docs.microsoft.com/zh-cn/dotnet/core/introduction](https://docs.microsoft.com/zh-cn/dotnet/core/introduction)
  - **教程集合**: 包含控制台应用、Web API、桌面应用等多种示例
  - **API参考**: 完整的类库API文档
  - **性能优化**: 最佳实践和基准测试指南
- **使用技巧**: 善用搜索功能和目录导航，遇到问题第一时间查阅

---

### 4. C# 编程指南

**链接**: [https://docs.microsoft.com/zh-cn/dotnet/csharp/](https://docs.microsoft.com/zh-cn/dotnet/csharp/)

**中文说明**: C#语言的完整编程指南，从语法基础到高级特性（LINQ、异步编程、模式匹配等），是掌握C#的必备资源。

**使用建议**:
- **适合人群**: 需要巩固或提升C#技能的开发者
- **重点章节（按优先级）**:
  1. **C# 基础概念**: 变量、类型、运算符、控制流
  2. **面向对象编程**: 类、接口、继承、多态
  3. **LINQ 查询**: 数据查询和转换的标准方式
  4. **异步编程**: async/await 模式（Web开发必备）
  5. **新特性**: C# 10-12的最新语法糖
- **配合练习**: 每学完一个概念立即编写代码验证

---

### 5. Entity Framework Core 文档

**链接**: [https://learn.microsoft.com/zh-cn/ef/core/](https://learn.microsoft.com/zh-cn/ef/core/)

**中文说明**: EF Core是.NET官方推荐的ORM框架，本文档涵盖模型创建、数据查询、迁移、性能优化等完整内容，当前最新版本为EF Core 9.0。

**使用建议**:
- **适合人群**: 需要进行数据库操作的开发者
- **学习路径**:
  1. **入门**: 创建第一个EF Core应用
  2. **建模**: 定义实体关系（一对一、一对多、多对多）
  3. **查询**: LINQ to Entities 查询语法
  4. **迁移**: 数据库版本管理和更新
  5. **进阶**: 性能优化、批量操作、并发处理
- **实战建议**: 先用Code First方式创建简单CRUD应用，再逐步复杂化

---

### 6. ASP.NET Core API 参考文档

**链接**: [https://learn.microsoft.com/zh-cn/aspnet/core/](https://learn.microsoft.com/zh-cn/aspnet/core/)

**中文说明**: ASP.NET Core框架的完整参考文档，包括MVC、Razor Pages、Blazor、SignalR、gRPC等技术栈的详细说明和API参考。

**使用建议**:
- **适合人群**: 正在进行Web应用开发的开发者
- **核心主题**:
  - **基础知识**: 中间件管道、依赖注入、配置系统
  - **路由与控制器**: RESTful API设计
  - **身份验证与授权**: JWT、Cookie、OAuth 2.0
  - **部署发布**: Docker、Azure、IIS部署方案
- **版本选择**: 文档支持多个版本（6.0/7.0/8.0/9.0），请根据实际使用的SDK版本选择对应文档

## 三、学习路线图建议

```
第一阶段（第1-2周）: 快速入门
├── 完成 ASP.NET Core 入门教程
└── 跑通第一个Blazor/MVC应用

第二阶段（第3-4周）: 夯实基础
├── 系统学习C#编程指南（重点：面向对象、LINQ、异步）
└── 理解.NET平台核心概念

第三阶段（第5-6周）: Web开发深入
├── 学习ASP.NET Core核心文档（中间件、DI、路由）
└── 完成Microsoft Learn完整路径

第四阶段（第7-8周）: 数据持久化
├── 掌握EF Core基本用法
└── 实现完整的CRUD功能

第五阶段（持续）: 进阶提升
├── 阅读API参考文档解决实际问题
├── 学习身份验证、部署等高级话题
└── 参与开源项目或构建个人作品集
```

## 四、实用技巧

1. **收藏常用页面**: 将上述链接加入浏览器书签，方便随时查阅
2. **善用搜索**: 在文档页面使用 Ctrl+F 快速定位关键词
3. **关注更新**: 微软文档会随版本更新，定期查看"新增功能"页面
4. **离线阅读**: 部分文档支持PDF下载，可在无网络时学习
5. **社区反馈**: 文档底部通常有"反馈"按钮，发现错误可提交改进建议
